## 一、安星排法原理

### 1.1 紫微系六星排布口诀

> "紫微天机逆行旁，隔一阳武天同当，又隔二位廉贞地，空三复见紫微郎。"[卷二·安星诀]

- **紫微系六星**：紫微→天机（逆隔一）→太阳（再隔一）→武曲（再隔一）→天同（再隔一）→廉贞（空三复见紫微）
- **天府系八星**：天府→太阴（顺一）→贪狼→巨门→天相→天梁→七杀（空三）→破军（空三复见天府）
- **镜像关系**：紫微与天府在寅申线上镜像对称——紫微在寅即天府在申，紫微在申即天府在寅

### 1.2 十二宫安宫顺序

```
一命宫、二兄弟、三妻妾（夫妻）、四子女、五财帛、六疾厄、
七迁移、八奴仆（交友）、九官禄、十田宅、十一福德、十二父母
```

男女俱从逆转。[卷二·安身命例]
