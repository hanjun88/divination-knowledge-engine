# 跨领域联动规则 (Cross-Domain Integration)

> **版本**：v1.0 | 2026-09-15
> **用途**：说明八个业务领域之间的联动分析规则，当用户问题涉及多个领域时的联合判定逻辑

---

## 一、领域联动总览

```
用户问题
  │
  ├─ 命理类（六爻/紫微/八字/Vedic/Western）→ 命盘/卦象分析
  │     │
  │     └─ 关系/心理类（依恋/亲密/疗愈）→ 心理维度补充
  │
  ├─ 关系类（依恋/亲密）→ 互动模式分析
  │     │
  │     └─ 命理类 → 命理维度验证（如夫妻宫+依恋风格联合判定）
  │
  └─ 疗愈类（创伤/躯体）→ 症状与疗愈分析
        │
        └─ 依恋类 → 依恋创伤溯源
        └─ 命理类 → 命理时间窗口（大运/行运触发期）
```

---

## 二、核心联动规则

### 2.1 八字 + 依恋模式联合分析

**触发条件**：用户提供八字且询问关系模式/情感困扰

**联动逻辑**：
1. 先用八字判定日主旺衰、格局、夫妻宫（日支）状态
2. 再用依恋模式技能判定行为表现对应的依恋风格
3. 联合判定规则：

| 八字特征 | 可能对应的依恋倾向 | 联动分析要点 |
|---|---|---|
| 日主弱+官杀重+印星无力 | 焦虑型倾向 | 外在压力大、自我价值感低，依恋系统易过度激活 |
| 日主旺+比劫重+财星弱 | 回避型倾向 | 自主性强、情感表达抑制，去激活策略 |
| 伤官旺+官杀混杂+印星受损 | 混乱型倾向 | 内在冲突剧烈、亲密关系中反复创伤 |
| 日主中和+官印相生+财星有根 | 安全型倾向 | 内在资源充足、关系弹性好 |
| 日支逢冲+夫妻宫不稳 | 依恋创伤易感 | 关系中分离焦虑高，需结合疗愈技能 |

**出处**：[滴天髓阐微·六亲论] + [attachment·四种依恋风格判定]

### 2.2 紫微斗数 + 心理疗愈联动

**触发条件**：用户提供紫微命盘且描述情绪/躯体症状

**联动逻辑**：
1. 紫微判定命宫/福德宫/疾厄宫主星与煞星组合
2. 心理疗愈技能判定创伤反应类型与神经系统唤起状态
3. 联合判定规则：

| 紫微特征 | 可能的心理/躯体倾向 | 联动分析要点 |
|---|---|---|
| 命宫七杀/破军+煞星重 | 战斗型(Fight)反应倾向 | 高交感唤起、易怒、控制欲，需SE躯体调节 |
| 命宫天机/太阴+煞星+福德宫空劫 | 焦虑/冻结混合倾向 | 思虑过度、躯体化，需Polyvagal调节 |
| 疾厄宫廉贞/天相+煞星 | 躯体症状易感 | 情绪通过身体表达，需躯体追踪 |
| 福德宫贪狼/廉贞+化忌 | 成瘾/冲动行为倾向 | IFS消防员部分活跃，需IFS工作 |
| 大限/流年触发命宫冲照 | 创伤触发时间窗口 | 大运/流年与创伤记忆的时间对应 |

**出处**：[紫微斗数全书·诸星问答论] + [trauma·4F生存反应]

### 2.3 六爻 + 亲密关系联动

**触发条件**：用户用六爻占问感情/婚姻，且描述了具体互动模式

**联动逻辑**：
1. 六爻判定世应关系、用神旺衰、应期
2. 亲密关系技能判定互动模式（追逐-退缩等）
3. 联合判定规则：

| 六爻特征 | 对应的关系互动模式 | 联动分析要点 |
|---|---|---|
| 世爻旺应爻衰+世克应 | 追逐-退缩中的追逐方 | 一方需求高、一方退缩，需EFT软情感对话 |
| 应爻旺世爻衰+应克世 | 追逐-退缩中的退缩方 | 同上，视角反转 |
| 世应相冲+用神空亡 | 冲突循环+情感撤回 | 冲突升级风险，需修复尝试 |
| 世应相合+动爻化进 | 关系正向发展 | 安全运作模式，可强化 |
| 用神月破+日辰生 | 关系创伤但有修复资源 | 依恋损伤但外部支持存在 |

**出处**：[增删卜易·婚姻章] + [intimate·伴侣互动模式]

### 2.4 Vedic + Western 占星联合

**触发条件**：用户同时提供或询问两种占星体系

**联动逻辑**：
1. Vedic用恒星黄道，Western用回归黄道，差异约24°
2. 联合判定规则：

| 维度 | Vedic视角 | Western视角 | 联合分析 |
|---|---|---|---|
| 上升 | Lagna（恒星黄道） | Ascendant（回归黄道） | 两体系上升可能不同星座，Vedic偏业力结构，Western偏心理面具 |
| 月亮 | Rashi为核心（情绪/心智） | Moon为情绪内在 | 两体系月亮星座通常相同（月亮移动慢），可互证 |
| 大运 | Dasha系统（时间序列） | Transit行运（行星触发） | Dasha定大运主题，Transit定具体触发时间 |
| 格局 | Yogas（星曜组合） | 相位+宫位 | Vedic Yoga偏宿命结构，Western相位偏心理动力 |
| 婚恋 | D9九分盘+Ashtakoota | Synastry比较盘+Composite | D9看灵魂契约，Synastry看互动动力 |

**注意**：两体系黄道不同，不可直接混排星曜位置，需分别排盘后对照解读。

**出处**：[BPHS·恒星黄道] + [western·四元素心理学]

### 2.5 依恋 + 心理疗愈联动

**触发条件**：用户描述关系困扰且有创伤症状

**联动逻辑**：
1. 依恋技能判定依恋风格与内部工作模型
2. 疗愈技能判定创伤反应类型与神经系统状态
3. 联合判定规则：

| 依恋风格 | 常见创伤反应 | 神经系统状态 | 疗愈路径 |
|---|---|---|---|
| 安全型 | 较少，有弹性 | 腹侧迷走为主 | 维持资源，预防性工作 |
| 焦虑型 | 战斗/讨好混合 | 交感过度唤起 | 接地+情绪调节+区分过去现在 |
| 回避型 | 冻结/逃跑 | 背侧迷走/解离 | 渐进式躯体接触+建立安全 |
| 混乱型 | 四种反应交替 | 三态切换不稳定 | 稳定化优先+IFS+SE整合 |

**出处**：[attachment·四种依恋风格] + [trauma·Polyvagal三态]

### 2.6 八字 + Vedic 联合

**触发条件**：用户同时提供八字和吠陀盘

**联动逻辑**：
1. 八字日主 ≈ Vedic Lagna主星（皆为命主核心）
2. 八字月令 ≈ Vedic Rashi（皆为时令核心）
3. 八字大运 ≈ Vedic Dasha（皆为时间序列）
4. 联合判定：两体系可互证大运主题，但具体应期各有体系，不混算

## 三、联动优先级与冲突解决

当多领域分析结论冲突时，按以下优先级处理：

1. **用户主诉优先**：用户最关心的问题维度权重最高
2. **时间精度**：六爻（一事一时）> Western行运（具体触发）> 八字/Vedic大运（主题）> 紫微大限（十年）
3. **心理vs命理**：命理定结构倾向，心理定行为模式，两者互补而非矛盾
4. **临床边界**：涉及心理症状时，疗愈技能的安全边界优先于命理结论
