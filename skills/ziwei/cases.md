# 紫微斗数格局判例库

> **来源**：《紫微斗数全书》（旧题宋·陈抟撰，明·罗洪先编）
> **体例**：每例含【星曜组合/宫位】【格局名称】【判定规则】【断语】【出处】
> **统计**：共 22 例（上格富贵 13 例 + 下格凶败 9 例）

## 一、上格富贵类

### 案 01｜君臣庆会

- **星曜组合/宫位**：紫微 + 左辅右弼同守命宫，更会相（天相）武（武曲）阴（太阴）
- **格局名称**：君臣庆会 / 辅弼夹帝
- **判定规则**：紫微守命，左辅右弼同宫或三方夹命，更会府相武阴
- **断语**：上格，材善经邦。"辅弼夹帝为上品""左府同宫尊居万乘"。紫微得辅弼如同帝得良相，无辅弼则为"孤君"。
- **出处**：[太微赋]"辅弼夹帝为上品"；[骨髓赋]"左府同宫尊居万乘"；[定贵局·君臣庆会]

### 案 02｜紫府同宫 / 紫府朝垣

- **星曜组合/宫位**：紫微天府同在寅申守命，加吉星活禄
- **格局名称**：紫府同宫 / 紫府朝垣
- **判定规则**：紫微天府同宫于寅申；或命坐寅申府相在财帛官禄朝照
- **断语**：终身福厚至三公。"紫府同宫终身福厚""紫府朝垣食禄万钟""寅逢府相位登一品之荣"。甲庚丁己生人财官格。
- **出处**：[骨髓赋]"紫府同宫终身福厚""紫府朝垣食禄万钟"；[卷三·论诸星同垣]

### 案 03｜府相朝垣

- **星曜组合/宫位**：命在寅申，天府天相在财帛宫、官禄宫朝照
- **格局名称**：府相朝垣
- **判定规则**：命宫寅申，府相分居财帛官禄二宫朝照
- **断语**：千钟食禄。"府相朝垣食禄万钟""府相同来会命宫全家食禄"。
- **出处**：[骨髓赋]"府相朝垣食禄万钟"；[定贵局·府相朝垣]

### 案 04｜日出扶桑 / 日丽中天

- **星曜组合/宫位**：太阳在卯守命（日出扶桑/日照雷门）；太阳在午守命（日丽中天）
- **格局名称**：日出扶桑 / 日丽中天
- **判定规则**：太阳居卯（卯为日出之地）或居午（午为日丽中天）
- **断语**：大富贵、专权之贵。"太阳居午，谓之日丽中天""日照雷门富贵荣华"。在午"日丽中天"主大富贵；在卯"日照雷门"富贵荣华。
- **出处**：[太微赋]"太阳居午，谓之日丽中天"；[骨髓赋]"日照雷门富贵荣华"；[定贵局·日出扶桑]

### 案 05｜月朗天门 / 水澄桂萼

- **星曜组合/宫位**：太阴在亥守命（月朗天门）；太阴在子守田宅或命（水澄桂萼）
- **格局名称**：月朗天门 / 水澄桂萼
- **判定规则**：太阴居亥（亥为天门，月朗于斯）；太阴居子（子为水澄之地）
- **断语**：清要之职、忠谏之材、进爵封侯。"太阴居子，号曰水澄桂萼""月朗天门进爵封侯"。丙丁生人夜时生合局，不贵则大富。
- **出处**：[太微赋]"太阴居子，号曰水澄桂萼"；[骨髓赋]"月朗天门进爵封侯"；[定贵局·月落亥宫]

### 案 06｜石中隐玉

- **星曜组合/宫位**：巨门在子午守命，更会科权禄
- **格局名称**：石中隐玉
- **判定规则**：命在子午逢巨门，三方四正会科权禄
- **断语**：官高极品。"子午巨门石中隐玉""巨门子午二宫逢，身命逢之必贵荣，更得三方科禄照，石中隐玉是丰隆"。
- **出处**：[骨髓赋]"子午巨门石中隐玉"；[论文星朝命格]；[定贵局·石中隐玉格]

### 案 07｜七杀朝斗 / 仰斗

- **星曜组合/宫位**：七杀在寅申子午守命，遇魁钺左右昌曲权禄
- **格局名称**：七杀朝斗 / 仰斗
- **判定规则**：七杀寅申子午四宫守命，遇魁钺左右昌曲权禄拱照
- **断语**：爵禄荣昌、四夷拱手。"七杀朝斗爵禄荣昌""七杀寅申子午宫，四夷拱手服英雄，魁钺左右文昌会，权禄名高食万钟"。
- **出处**：[骨髓赋]"七杀朝斗爵禄荣昌"；[七杀入男命吉凶诀]

### 案 08｜火贪格 / 铃贪格

- **星曜组合/宫位**：贪狼在寅午戌辰戌丑未庙旺，与火星或铃星同度三合
- **格局名称**：火贪格 / 铃贪格
- **判定规则**：贪狼庙旺与火星（火贪）或铃星（铃贪）同守命宫或三合照
- **断语**：指日立边庭、封侯食禄、威镇诸邦。"贪铃并守将相之名""贪狼火星居庙旺名镇诸邦""火遇贪狼照命宫，封侯食禄是英雄"。寅午戌人、东南生人合局。
- **出处**：[骨髓赋]"贪铃并守将相之名""贪狼火星居庙旺名镇诸邦"；[火星歌]；[铃星歌]

### 案 09｜巨日同宫

- **星曜组合/宫位**：巨门与太阳同在寅申，或巨在亥日在巳
- **格局名称**：巨日同宫
- **判定规则**：巨门太阳同宫于寅申
- **断语**：官封三代、食禄驰名。"巨日同宫官封三代"。
- **出处**：[骨髓赋]"巨日同宫官封三代"；[卷三·论诸星同垣]

### 案 10｜巨机同宫

- **星曜组合/宫位**：巨门与天机同在卯（或酉）
- **格局名称**：巨机同宫
- **判定规则**：巨门天机同宫于卯（吉）或酉（凶）
- **断语**：公卿之位（卯吉酉凶）。"巨机同宫公卿之位"。卯上巨机为贵格，武曲守卯福丰盈；酉宫虽美无始终。
- **出处**：[骨髓赋]"巨机同宫公卿之位"；[十二宫得地诀]"卯宫机巨武曲逢"

### 案 11｜机月同梁

- **星曜组合/宫位**：天机、太阴、天同、天梁会寅申命
- **格局名称**：机月同梁
- **判定规则**：命在寅申，三方四正会天机太阴天同天梁
- **断语**：作吏人（稳定文职）。"机月同梁作吏人"。加吉不论，无吉无杀亦是平常人，凶杀空劫化忌为下格。
- **出处**：[骨髓赋]"机月同梁作吏人"；[卷三·论诸星同垣]"机月同梁作吏人"

### 案 12｜武贪同行

- **星曜组合/宫位**：武曲与贪狼在丑未同宫，加火星
- **格局名称**：武贪同行 / 武贪墓中居
- **判定规则**：武曲贪狼同宫于丑未，加火星
- **断语**：先贫后富、三十年后发福、威镇边夷。"贪武同行威镇边夷""贪武墓中居三十才发福"。戊己庚生人贵格。
- **出处**：[骨髓赋]"贪武同行威镇边夷""贪武墓中居三十才发福"

### 案 13｜禄马交驰

- **星曜组合/宫位**：禄存与天马同宫
- **格局名称**：禄马交驰 / 折鞭马
- **判定规则**：禄存天马同宫守命身
- **断语**：发财远郡、白手起家。"禄马最喜交驰""天禄天马惊人甲第""禄存对向守迁移，三合逢之利禄宜，得逢遐迩人钦敬，的然白手起家基"。
- **出处**：[太微赋]"禄马最喜交驰"；[骨髓赋]"天禄天马惊人甲第"；[定贵局·禄马佩印]

## 二、下格凶败类

### 案 14｜泛水桃花

- **星曜组合/宫位**：贪狼在亥子，遇羊陀
- **格局名称**：泛水桃花
- **判定规则**：贪狼居亥子水位，加擎羊陀罗
- **断语**：男女贪花迷酒丧身。"贪居亥子，名为犯水桃花"。亥子"泛水桃花"，迷花恋酒丧命。
- **出处**：[太微赋]"贪居亥子，名为犯水桃花"；[诸星问答论·贪狼]"亥子泛水桃花"

### 案 15｜风流彩杖

- **星曜组合/宫位**：陀罗与贪狼在寅宫
- **格局名称**：风流彩杖
- **判定规则**：陀罗贪狼同宫于寅
- **断语**：风流惹祸。"刑遇贪狼，号曰风流彩杖"。因酒色以成痨。
- **出处**：[太微赋]"刑遇贪狼，号曰风流彩杖"；[诸星问答论·陀罗]"与贪狼同度因酒色以成痨"

### 案 16｜路上埋尸

- **星曜组合/宫位**：七杀与廉贞同宫
- **格局名称**：路上埋尸
- **判定规则**：廉贞七杀同宫守命身
- **断语**：凶横伤亡。"七杀廉贞同位，路上埋尸"。廉贞七杀反为积富之人（在丑未加吉），同位则路上埋尸（凶横）。
- **出处**：[太微赋]"七杀廉贞同位，路上埋尸"；[骨髓赋]"廉贞七杀反为积富之人"

### 案 17｜水中作冢

- **星曜组合/宫位**：破军与暗曜（巨门/化忌）同乡
- **格局名称**：水中作冢
- **判定规则**：破军与巨门或化忌同宫于水位
- **断语**：溺水横死。"破军暗曜同乡，水中作冢"。破军与文曲入于水域，残疾离乡。
- **出处**：[太微赋]"破军暗曜同乡，水中作冢"；[诸星问答论·破军]"与文曲入于水域，残疾离乡"

### 案 18｜反背 / 失辉

- **星曜组合/宫位**：日月反背（日戌月辰、月子午）
- **格局名称**：日月反背 / 失辉
- **判定规则**：太阳在戌亥子失辉，太阴在卯辰巳午失陷
- **断语**：劳碌贫贱、克夫克父。"日月最嫌反背""日月最嫌反背乃为失辉"。日在戌亥为西没失辉，月在卯辰巳午为落陷。
- **出处**：[太微赋]"日月最嫌反背"；[骨髓赋]"日月最嫌反背乃为失辉"

### 案 19｜极居卯酉

- **星曜组合/宫位**：紫微在卯酉，遇劫空四杀
- **格局名称**：极居卯酉
- **判定规则**：紫微守命卯酉，加地空地劫羊陀火铃
- **断语**：脱俗僧人、公胥吏辈。"极居卯酉多为脱俗僧人，贞居卯酉定是公胥吏辈""紫微卯酉劫空四杀多为脱俗之僧"。
- **出处**：[骨髓赋]"极居卯酉多为脱俗僧人，贞居卯酉定是公胥吏辈"；[卷三·论诸星同垣]

### 案 20｜马头带剑

- **星曜组合/宫位**：午宫守命带擎羊（或天同+天梁+擎羊在午）
- **格局名称**：马头带剑
- **判定规则**：午宫守命带擎羊
- **断语**：镇卫边疆，但非夭折即刑伤。"马头带剑，镇卫边疆""马头带剑非夭折则主刑伤"。
- **出处**：[太微赋]"马头带剑，镇卫边疆"；[骨髓赋]"马头带剑非夭折则主刑伤"；[定贵局·马头带剑]

### 案 21｜刑囚夹印

- **星曜组合/宫位**：天刑 + 廉贞（囚）夹/临天相（印）
- **格局名称**：刑囚夹印
- **判定规则**：天刑廉贞夹或临天相
- **断语**：刑杖、武勇。"刑囚夹印，刑杖惟司"。天相廉贞擎羊来多招刑杖难逃。
- **出处**：[太微赋]"刑囚夹印，刑杖惟司"；[定贵局·刑囚夹印]；[天相断]"天相廉贞擎羊来多招刑杖难逃"

### 案 22｜禄逢冲破 / 马遇空亡

- **星曜组合/宫位**：禄存/化禄逢空亡冲照；天马落截空/旬空
- **格局名称**：禄逢冲破 / 马遇空亡
- **判定规则**：禄存化禄逢地空地劫冲照；天马落空亡
- **断语**：禄逢冲破，吉处藏凶；马遇空亡，终身奔走。"禄逢冲破，吉处藏凶""马遇空亡，终身奔走"。
- **出处**：[太微赋]"禄逢冲破，吉处藏凶""马遇空亡，终身奔走"；[诸星问答论·天马]

## 四、格局判定总则

1. **入格须庙旺**："如命入格，庙旺聚吉，科权禄守，上上之命。不入庙加吉化，科权禄，上次之命。"[谈星要论·论人命入格]
2. **格破不化吉**："入格不化吉而化凶，只以本命吉凶多寡而断之。"[谈星要论]
3. **星数相配**："凡星得上格而数得上格为第一，位至极品之贵。"[谈星要论·论格星数高下]
4. **吉多凶少**："诸星吉多逢凶也吉，诸星恶多逢吉也凶。"[重补斗数彀率]
5. **主强宾弱**："主强宾弱可保无虞，主弱宾强凶危立见。"[斗数发微论]
