## 1. 技能包能力范围

本技能包将三部古典占卜/命理典籍体系模块化封装，覆盖：

- **六爻纳甲筮法**：具体一事一时的吉凶断卦，应期推断
- **紫微斗数**：一生命局格局判定、十二宫专断、限运提示
- **八字命理**：日主旺衰用神取定、大运吉凶、人生趋向

三体系互参：[shared/glossary.md](./shared/glossary.md) 提供约 90 个核心术语的跨体系对照。

## 3. 三个子技能调用方式

### 3.1 路由判定（总入口路由逻辑）

```
用户问题
  ├─ "占/卜/卦/测/问一事" + 已排六爻卦象
  │    → 调用 liuyao/SKILL.md
  ├─ "命盘/紫微/十二宫/星曜/格局/大限" + 紫微命盘
  │    → 调用 ziwei/SKILL.md
  ├─ "八字/四柱/日主/用神/大运/格局/乾造坤造" + 八字
  │    → 调用 bazi/SKILL.md
  └─ 跨体系查询/术语对照
       → 调用 shared/glossary.md
```

### 3.2 子技能调用参数

| 子技能 | 必填输入 | 可选输入 | 输出格式 |
|---|---|---|---|
| liuyao | 月建/日辰/旬首/六爻数组/世应/事类 | 动爻变爻/暗动/卦名 | JSON（用神+四神+旺衰+应期） |
| ziwei | 命宫主星/十二宫星曜/生年四化/性别/夜生 | 煞曜/限运 | JSON（格局+三方四正+四化+宫断） |
| bazi | 四柱/性别/日主/月令/大运 | 当前大运/事类 | JSON（旺衰+用神+格局+大运） |

## 4. 适用场景

### 4.1 六爻适用场景

- 当下一事一占：功名、求财、婚姻、疾病、行人、出行、官司、失物
- 应期推断：何时成/何时败/何日应
- 多卦合参：再占法合决
- **不适用**：一生命局、性格分析、大运趋势

### 4.2 紫微适用场景

- 一生命局整体格局
- 十二宫专断：事业、婚姻、财运、子女、田宅、健康
- 大限十年运势、小限流年
- 男女命差异（女命夫子二宫为重）
- **不适用**：具体一事一时吉凶（六爻更准）

### 4.3 八字适用场景

- 一生命局旺衰与用神
- 大运十年吉凶与人生趋向
- 性格、事业、财运、婚姻、子女、寿元
- 调候（冬火夏水）
- **不适用**：具体一事一时吉凶（六爻更准）

## 5. 与规则引擎 API 的协作关系

### 5.1 分工

```
规则引擎 API（外部）
  ├─ 六爻：排卦（摇卦/时间起卦/数字起卦→成卦→装六亲→定世应→查月破旬空）
  ├─ 紫微：安星排盘（定命宫→起紫微→安十四正曜→安辅曜煞曜→定四化）
  └─ 八字：排四柱（定年柱→月柱→日柱→时柱→起大运→定流年）

本技能包（解读层）
  ├─ liuyao/    ：接收已排好的卦象，做旺衰加权+四神联动+吉凶总判+应期推断
  ├─ ziwei/     ：接收已安星的命盘，做格局判定+三方四正合参+四化裁定+宫断
  └─ bazi/      ：接收已排好的四柱大运，做旺衰+用神取定+格局+大运吉凶
```

### 5.2 数据流

```
用户提问 → 规则引擎API排盘 → 本技能包解读 → 结构化JSON输出
                ↑                    ↑
          (排卦/安星/排四柱)      (断卦/论命/应期)
```

### 5.3 边界

- **本技能包不做排盘**：排卦/安星/排四柱由规则引擎API完成
- **本技能包只做解读**：基于已排好的象，按古籍规则做判定
- **API对接点**：规则引擎API输出标准JSON排盘结果→本技能包输入JSON解读参数

## 8. 注意事项与边界

1. **三体系不可混用**：六爻断一事，紫微八字论一生，不可用八字断当下一事，不可用六爻论一生命局。
2. **排盘与解读分离**：本技能包只做解读，排盘由规则引擎API完成。
3. **古籍底本边界**：
   - 六爻：以《增删卜易》经验派为骨架，凡与古法分歧处以野鹤占验修正为准
   - 紫微：以《全书》南派四卷本为据，五行局逐盘未展开，流曜飞动未拓扑
   - 八字：以任铁樵旺衰喜忌为骨架，辟物象拟人/神煞纳音/桃花专论女命
4. **不用之项**：
   - 六爻：六神/神煞/卦身/六害/互卦
   - 紫微：五行局逐盘枚举/流曜飞动/卷四图版
   - 八字：物象拟人/神煞纳音/奇格异局妄谈
5. **多占法**：六爻卦不分明时须再占一卦合决之，不可妄断。
6. **调候为急**：八字冬月用火夏月用水，调候用神重于扶抑用神。
7. **庙旺为第一义**：紫微吉曜陷地减色，凶星庙旺反为福。
