> **来源**：《增删卜易》《卜筮正宗》《黄金策》《易隐》
> **用途**：断卦时快速查阅旺衰权值、月破旬空、生克优先级、应期口诀
> **权值标度**：-3 ~ +3 整数制（正为帮扶/有气，负为克泄/败气）

### 1.5 综合旺衰分级

```
score = 月建权值 + 日辰权值 + 动爻群权值 + 变爻回照权值

score ≥ 4   → 太旺/旺相（喜墓库收藏，应期逢墓逢冲）
score ≥ 1   → 有气/旺
score ≥ -1  → 中和/平
score ≥ -3  → 休囚/衰
score < -3  → 无气/极弱
```

**两条修正铁律**：
1. **寡不敌众**：临月建/日辰之爻，若卦中动爻成群克之，破亦为破、伤亦为伤。
2. **用神无根**：月破+日克，"值月破而被克，虽有生扶之不起"，元神有力亦难生。

## 二、月破旬空速查

### 2.1 月破对照表

| 月建 | 破爻 | 月建 | 破爻 |
|---|---|---|---|
| 寅 | 申 | 申 | 寅 |
| 卯 | 酉 | 酉 | 卯 |
| 辰 | 戌 | 戌 | 辰 |
| 巳 | 亥 | 亥 | 巳 |
| 午 | 子 | 子 | 午 |
| 未 | 丑 | 丑 | 未 |

**月破真假判定**：
- **真破（到底破）**：静而不动 + 无日辰动爻生助 + (旬空 OR 休囚 OR 被克)
- **待实之破**：动而月破 / 得生扶 → 出月/填实/逢合方解
- **破而不破**：爻临日建，虽月破不为破

### 2.2 旬空对照表

| 旬首 | 空亡 | 旬首 | 空亡 |
|---|---|---|---|
| 甲子 | 戌、亥 | 甲申 | 午、未 |
| 甲戌 | 申、酉 | 甲午 | 辰、巳 |
| 甲辰 | 寅、卯 | 甲寅 | 子、丑 |

**真空 vs 假空**：
- **假空（出旬有用）**：旺相 / 发动 / 得日辰动爻生扶 / 动而化空 / 伏而旺相
- **真空（到底空）**：月破 / 有气不动又被克 / 伏而被克 / 春土夏金秋木冬火

**冲空则实**：日辰冲空爻 → 出空填空

### 2.3 叠加处理优先级

```
RULE-STACK-1: 月破+旬空+休囚+安静+被克 → 真破真空，最凶
RULE-STACK-2: 月破+旬空但发动/得生扶 → 双填之期应事
RULE-STACK-3: 月破但值日建 → 破而不破
RULE-STACK-4: 旬空但临月建 → 旬内毕竟为空，出旬不为空
RULE-STACK-5: 先判月破，再叠旬空；皆待用则取双填之期
```

## 三、生克优先级速查

### 3.1 权威权重排序

```
月建(令星) > 日辰(主宰) > 动爻(明动/暗动) > 变爻回照 > 静爻
```

### 3.2 生克路线优先级

| 级别 | 作用者 | 说明 |
|---|---|---|
| 第1级 | 月建、日辰 | 如天，能生克一切爻；诸爻不能伤日月 |
| 第2级 | 动爻（明动+暗动） | 动能克静，静旺不能克动 |
| 第3级 | 变爻 | 仅对本位动爻回照，不及其余；唯日月能制变爻 |
| 第4级 | 静爻 | 仅旺相静爻可生克休囚静爻 |

### 3.3 介入修正

- **贪生忘克/贪合忘冲**：动爻若旁逢生合，则忘克忘冲
- **合绊**：动逢合=绊住(-1)；静逢合=合起(+1)
- **三合局**：成局以局五行论生克；局克世为凶，局生世为吉
- **六冲**：冲者散也；凶事宜散，吉事宜忌

## 四、四神联动速查

### 4.1 原神有力（五条件任一）

1. 旺相 / 临日月 / 动爻生扶
2. 动化回头生 / 化进神
3. 长生/帝旺于日辰
4. 与忌神同动（贪生忘克，忌反生原）
5. 旺动临空化空（动不为空，冲空实空之日有用）

### 4.2 原神无力（六条件任一）

1. 休囚不动 / 动而休囚又被伤克
2. 休囚又逢旬空月破
3. 休囚动化退神
4. 衰而又绝
5. 入三墓（日墓/动墓/化墓）
6. 休囚动化绝/化克/化破/化散

### 4.3 忌神有力（五条件任一）

1. 旺相 / 遇日月动爻生扶 / 临日月
2. 动化回头生 / 化进神
3. 旺动临空化空
4. 长生/帝旺于日辰
5. 与仇神同动

### 4.4 忌神无力（七条件任一）

1. 休囚不动 / 动而休囚被日月动爻克
2. 静临空破
3. 入三墓
4. 衰动化退神
5. 衰而又绝
6. 动化绝/化克/化破/化散
7. 与原神同动（贪生忘克，反生原神）

### 4.5 总校验

- **用神无根**（月破+日克 OR 无一点生扶）→ "元神有力亦难生，忌神无力何足喜"，不论原忌旺衰直断凶
- **贪生忘克**：忌神动+原神动同卦 → 忌神贪生原神，忘克用神，化凶为吉
- **避空避凶**：忌神独发+用神旬空/伏藏 → 用神避空避凶，待出空出透方受其毒
