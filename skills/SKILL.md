## 1. 技能包能力范围

本技能包将八个业务领域模块化封装，覆盖命理占卜与心理关系两大体系：

### 命理占卜体系（5个领域）
- **六爻纳甲筮法**：具体一事一时的吉凶断卦，应期推断
- **紫微斗数**：一生命局格局判定、十二宫专断、限运提示
- **八字命理**：日主旺衰用神取定、调候格局、大运吉凶
- **印度星盘(Vedic)**：恒星黄道本命盘、D9九分盘、二十七宿、Dasha大运、Yogas格局
- **西方星盘(Western)**：心理占星本命解读、相位分析、行运次限、比较盘

### 心理关系体系（3个领域）
- **依恋模式**：四种依恋风格判定、内部工作模型、AAI要点、配对互动
- **亲密关系**：伴侣互动模式识别、EFT情感聚焦、冲突循环、欲望与亲密张力
- **心理疗愈**：4F创伤反应、Polyvagal神经调节、SE躯体追踪、IFS次人格、CPTSD图谱

### 跨领域联动
- [shared/glossary.md](./shared/glossary.md)：八领域术语对照表（约150术语）
- [shared/cross_domain.md](./shared/cross_domain.md)：跨领域联动规则（八字+依恋、紫微+疗愈、六爻+亲密等6组联合判定）

## 3. 八领域路由判定

```
用户问题
  │
  ├─ 含"占/卜/卦/测/问一事" + 已排六爻卦象 → liuyao（六爻）
  ├─ 含"紫微/命盘/十二宫/星曜/格局/大限" → ziwei（紫微斗数）
  ├─ 含"八字/四柱/干支/日主/大运/流年/调候" → bazi（八字）
  ├─ 含"吠陀/印度星盘/Vedic/Dasha/Nakshatra/Lagna" → vedic（印度星盘）
  ├─ 含"星盘/上升/星座/相位/行运/比较盘/Transit" → western（西方星盘）
  ├─ 含"依恋/焦虑型/回避型/安全型/分离焦虑/AAI" → attachment（依恋模式）
  ├─ 含"伴侣/婚姻/冲突/沟通/情感需求/EFT/欲望" → intimate（亲密关系）
  ├─ 含"创伤/闪回/冻结/CPTSD/躯体/IFS/迷走神经/PTSD" → trauma（心理疗愈）
  │
  └─ 涉及多个领域 → 调用 cross_domain.md 联动规则
```

## 4. 与规则引擎API的协作

本技能包与 `engine/` 目录的FastAPI规则引擎协作：

- 命理三域（liuyao/ziwei/bazi）的判定规则已编译为206条DSL规则JSON
- 技能包提供断法流程、判例参考和速查表
- API提供毫秒级规则匹配：`POST /api/liuyao/analyze`、`/api/ziwei/analyze`、`/api/bazi/analyze`
- 心理关系五域（vedic/western/attachment/intimate/trauma）目前为技能包蒸馏规则，可后续编译为规则JSON

全部130个判例均标注出处，可与 `books/` 目录的10本古籍原文交叉对照：

- 心理关系判例标注理论体系（如 `[Bowlby·依恋三部曲]`、`[CPTSD·情绪闪回]`、`[EFT·情绪聚焦]`）

## 6. 通用边界

- 命理占卜：提供结构倾向与时间窗口，非宿命定论
- 心理关系：提供分析框架与自助引导，非临床诊断/治疗替代
- 急性危机（自伤/伤人/家暴）：立即转介专业帮助，不做技能分析
- 现代版权书籍：仅放蒸馏后的规则与断法，不放原书全文
