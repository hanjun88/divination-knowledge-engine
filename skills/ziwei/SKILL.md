# 紫微斗数技能 (Ziwei Doushu Skill)

> **底本**：《紫微斗数全书》（旧题宋·陈抟撰，明·罗洪先编，南派四卷本系统）
> **编译依据**：`紫微斗数赋文拓扑编译.md`（42 颗星、十二宫全映射、25 种格局变体）
> **版本**：v1.0 | 2026-09-15

---

## 1. 技能名称与描述

**ziwei-divination**：基于紫微斗数星曜体系的命盘解读引擎。输入一张已安星的紫微命盘（命宫主星、十二宫星曜、四化、三方四正），按赋文规则输出格局判定、性情论断、宫位吉凶与限运提示。

本技能以《全书》卷一《太微赋》《骨髓赋》《诸星问答论》为义理母本，卷二《安星诀》《十二宫诸星断》为排盘与分宫断语，卷三《谈星要论》《论诸星同垣》为格局裁定。

---

## 2. 触发条件

当用户提出以下需求时触发本技能：
- 提供一张紫微命盘（命宫主星、十二宫星曜分布、生年四化），要求论命
- 问格局判定（"我这个盘是什么格？"）
- 问十二宫专项：命宫/夫妻/财帛/官禄/迁移/田宅/福德/疾厄/子女/交友/兄弟/父母
- 问星曜组合吉凶（"紫微+破军同宫如何？"）
- 问大限/小限/流年提示
- 问男女命差异（女命格局、夫夫子二宫）

**不触发**：仅问安星排盘（排盘由规则引擎 API 完成）、问六爻/八字体系问题、要求排八字。

## 4. 核心断法步骤（从古籍编译的判定流程）

### 步骤 1：定命宫主星与基本格局

先看命宫主星（十四正曜之一），查 [galaxy_matrix.md](./galaxy_matrix.md) 对应星系：

| 命宫主星 | 基本倾向 | 喜 | 忌 |
|---|---|---|---|
| 紫微 | 帝座、官禄主 | 辅弼昌曲魁钺府相 | 破军同、四杀冲破 |
| 天机 | 善星、兄弟主 | 天梁左右昌曲魁钺太阴 | 巨门+羊陀火铃忌 |
| 太阳 | 贵星、官禄主 | 太阴左右昌曲魁钺禄存 | 巨暗、落戌亥子失辉 |

### 步骤 2：查格局（定贵贫贱）

对照 [cases.md](./cases.md) 中的 22 种命名格局：

**上格（富贵）**：
- 君臣庆会（紫微+辅弼同守命）
- 紫府同宫/紫府朝垣（寅申）
- 府相朝垣（命寅申，府相在财官朝照）
- 日出扶桑（太阳在卯）/日丽中天（太阳在午）
- 月朗天门（太阴在亥）/水澄桂萼（太阴在子）
- 石中隐玉（巨门在子午，会科权禄）
- 七杀朝斗/仰斗（七杀在寅申子午）
- 火贪格/铃贪格（贪狼庙旺+火/铃同度）
- 巨日同宫（巨门+太阳在寅申）
- 武贪同行（武曲+贪狼在丑未，加火星）
- 禄马交驰（禄存+天马同宫）
- 极向离明（紫微在午，无刑忌）

**下格（贫贱/凶）**：
- 泛水桃花（贪狼在亥子遇羊陀）
- 风流彩杖（陀罗+贪狼在寅）
- 路上埋尸（七杀+廉贞同宫）
- 水中作冢（破军+暗曜同乡）
- 反背/失辉（日月反背：日戌月辰、月子午）
- 极居卯酉（紫微在卯酉遇劫空四杀）
- 马头带剑（午宫守命带擎羊）

### 步骤 3：三方四正合参

```
命宫三方四正 = 命宫 + 财帛宫 + 官禄宫 + 迁移宫（对宫）
```

- 三方吉拱为上格；凶星冲照破格
- **强宫**（男命）：财帛、官禄、福德、迁移、田宅
- **弱宫**（男命）：子女、奴仆、兄弟、父母
- **强宫**（女命）：夫君、子息、财帛、田宅、福德

### 步骤 4：四化飞星裁定

[十干化曜表见 galaxy_matrix.md]

- 化禄：守身命官禄主进财；**禄出何宫即何宫得资源**
- 化权：守身命科禄相逢出将入相；**权出何宫即何宫掌权**
- 化科：守身命权禄相逢宰臣之贵；**科出何宫即何宫得名声**
- 化忌：守身命一生不顺；**忌出何宫即何宫生阻**。入庙反为佳（如天同在戌丁人、巨门在辰辛人、日月庙旺化忌反福）

**四化总则**：
- 禄权科忌三合拱命为上格（"科权禄拱名誉昭彰"）
- 双忌冲照（对宫）最凶
- 大限十年一转，小限一年一转，太岁为当年司令

### 步骤 5：十二宫专项论断

按所问事项，查 [galaxy_matrix.md](./galaxy_matrix.md) 中对应宫位的主星断语：

| 所问 | 查宫 | 核心看 |
|---|---|---|
| 性情外貌 | 命宫 | 主星庙旺失陷、形性赋 |
| 事业功名 | 官禄宫 | 主星吉凶、化禄化权 |
| 财运 | 财帛宫 | 武曲天府太阴禄存 |
| 婚姻 | 夫妻宫 | 主星庙旺、四杀刑克 |
| 子女 | 子女宫 | 主星吉凶、羊陀火铃空劫 |
| 健康 | 疾厄宫 | 主星疾病对应、化忌 |
| 出外 | 迁移宫 | 对宫照命、贵人扶持 |
| 田产 | 田宅宫 | 天府太阴、空劫 |
| 精神 | 福德宫 | 天同、空劫 |
| 父母 | 父母宫 | 天梁太阳太阴、刑克 |

### 步骤 6：限运提示

- **大限**：十年一转，依五行局起运
- **小限**：一年一转
- **流年太岁**：当年司令，二限太岁交临化忌断然蹭蹬
- 遇杀必惊，流年最紧；吉曜临限添福，凶曜临限招灾

## 7. 注意事项与边界

1. **庙旺失陷为第一义**：吉曜陷地减色，凶星庙旺反为福。"吉星入垣则为吉，凶星失地则为凶"。
2. **不执一宫断**：单看命宫不足，须三方四正合参，夹宫（左右夹、日月夹）亦重。
3. **女命别断**：女命先看夫子二宫，"若论女人之命，先观夫子二宫"；女命贵格反为无用，以子媳夫君福德为正强。
4. **身命同参**：命好身好限好到老荣昌；命衰身衰限衰终身乞丐。身宫与命宫同参。
5. **五行局盲区**：标准六十星系=紫微十二宫×五行局五局=60种盘，本书未逐局枚举，仅覆盖12种基本盘+25种命名变体。
6. **流曜未展开**：流禄流羊流陀流昌流曲流魁流钺仅提安法，未做飞动逻辑拓扑。
7. **南北斗分主应期**："阳男阴女南斗为福，北斗诸星大限断上五年；南斗诸星大限断下五年"仅原则性提及。
8. **卷四图版无文字**：命盘图须另行人工读图。
9. **空劫双刃**：地空地劫"遇吉则祸轻，与紫机梁同入僧道反清"，不可纯作凶断。
