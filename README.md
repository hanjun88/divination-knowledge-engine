# Divination Knowledge Engine（术数与心理知识引擎）

基于公版古籍与经典理论体系的八领域知识编译与规则引擎系统。将10本明清术数经典全文校勘整理，编译为206条可计算规则，封装为八领域Agent技能包（命理占卜5域 + 心理关系3域，共130个判例），并提供FastAPI推理服务。

### 校勘规范

- **结构化标记**：`## 卷X` 分卷，`### 篇名` 分章，段落间空行
- **句读标点**：对无标点古文添加现代标点，旧式句点统一规范
- **校勘记**：明显讹误、脱漏以 `[校：XXX]` 附于原文后，不直接改动底本
- **注文区分**：《滴天髓阐微》原注/任氏曰、《造化元钥》徐乐吾按语用引用块（`>`）区分
- **编码**：统一 UTF-8，无乱码
- **判例回溯**：skills/ 中所有判例引用均标注原书章节（如 `[增删·卷三]`、`[骨髓赋]`），可在 books/ 中交叉对照

## 规则引擎（engine/）

### DSL规则格式

```json
{
  "rule_id": "LY-001",
  "domain": "liuyao",
  "name": "用神得月建生扶",
  "conditions": [{"field": "月建", "operator": "生", "target": "用神"}],
  "actions": [{"conclusion": "用神得令", "detail": "月建生用神，用神有力"}],
  "weight": 3,
  "priority": 9,
  "source": "增删卜易·卷一"
}
```

| 领域 | 规则数 | 覆盖模块 |
|------|--------|----------|

| 八字 (bazi) | 60 | 滴天髓理气、命理约言格局、造化元钥调候、六亲、大运流年 |

### API端点

| Method | Path | 说明 |
|--------|------|------|
| GET | `/health` | 健康检查 + 各领域规则数 |
| GET | `/api/rules/{domain}` | 列出某领域规则 |
| POST | `/api/liuyao/analyze` | 六爻断卦 |
| POST | `/api/ziwei/analyze` | 紫微命盘分析 |

## 技能包（skills/）

八个业务领域的Agent技能包，共130个判例，每个标注出处可回溯：

### 命理占卜体系（5域）
- **六爻**：25例（增删卜易22 + 卜筮正宗3），含卦象/断语/应期验证
- **紫微**：22例格局判例（13上格 + 9下格）
- **八字**：22例任铁樵命例（滴天髓阐微18 + 造化元钥4），含四柱/大运/断语/验证
- **印度星盘(Vedic)**：12例经典格局（BPHS/Jaimini核心概念）
- **西方星盘(Western)**：12例配置案例（心理占星/相位/行运/比较盘）

### 心理关系体系（3域）
- **依恋模式**：12例（四风格判定/配对互动/AAI/earned-secure）
- **亲密关系**：12例（互动模式/EFT/冲突循环/欲望张力/修复）
- **心理疗愈**：13例（4F反应/Polyvagal/SE躯体追踪/IFS/CPTSD）

### 共享资源
- `shared/glossary.md`：八领域术语对照表（约150术语）
- `shared/cross_domain.md`：跨领域联动规则（八字+依恋、紫微+疗愈、六爻+亲密等6组联合判定）

每个技能含标准 YAML frontmatter 和7节规范：技能描述、触发条件、输入参数、核心断法步骤、判例引用、输出格式、注意边界。可在仓库根目录执行 `python3 tools/validate_skills.py` 校验元数据与相对链接；GitHub Actions 会在 Skill 相关文件变更时自动运行同一校验。现代版权书仅放蒸馏后的规则与断法，不收录原文。

## 知识编译链路

```
古籍原文 (books/, 10本, ~99万字)
    ↓ 校勘整理（分卷/句读/校勘记）
结构化文本
    ↓ 规则抽取（IF-THEN编译为DSL JSON）
规则JSON (engine/rules/, 206条，命理三域)
    ↓ 规则引擎匹配
FastAPI推理服务 (engine/)
    ↓ 判例封装（book-to-skill，八领域130判例）
Agent技能包 (skills/, 8域 + 跨领域联动)
```

## 公版声明

本仓库 books/ 目录所收10种书籍均为清代及以前著作，作者逝世已逾百年，进入公有领域。文本来源于公开古籍数字化平台（中华典藏网、国学大师等），经校勘整理后收录。skills/ 中心理关系领域的内容为现代理论体系的蒸馏规则与断法，不收录现代版权书籍原文。
