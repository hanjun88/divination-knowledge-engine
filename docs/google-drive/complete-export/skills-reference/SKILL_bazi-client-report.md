Bazi Client Report & Tiered Delivery System
概述与核心使命
本技能是面向商业客户终端交付的标准报告引擎。核心目标是把底层复杂的八字排盘与古典数理推演结果，转化为客户看得懂、用得上、极具获得感的10页·29大类·120+项全息交付报告。
技能严格执行两大铁律：
全量运算铁律：输入客户八字后，底层必须100%全量计算所有10个页面、29大类、120+项字段，绝不允许因缺少付费而偷工减料。
商业分级门控铁律：在交付渲染时，根据客户付费等级（FULL_VIP、FREE_TRIAL、SPECIAL_CAREER 等）或自选模块，动态渲染已解锁内容或高转化率的痛点遮罩卡片。

触发条件与适用场景
当出现以下任一场景时触发本技能：
用户要求生成给客户看的八字咨询报告或排盘交付清单
用户要求按10页、29大类、120+项结构输出完整的八字解读
用户要求实现命理报告的分级付费控制、试看截断或付费解锁机制
用户提供客户个人信息（姓名、出生时间、八字）并要求交付标准化商业报告

参数说明：
payment_tier：可选 FULL_VIP（默认全量10页）、FREE_TRIAL（第1-2页）、SPECIAL_CAREER（事业财富版）、SPECIAL_RELATIONSHIP（婚恋感情版）、SPECIAL_ANNUAL（流年运势版）、CUSTOM（自定义）。
若 payment_tier 未显式传入，默认采用 FULL_VIP 模式，输出全量120+项内容。

10页·29大类·120+项全息交付架构
报告严格分为十页，每页包含明确的板块与展示项：
第一页：命盘总览 (4大类)
基本信息：姓名、性别、公历时间、农历时间、真太阳时校正、生肖、现代星座。
四柱命盘：四柱（年月日时）、天干、天干十神、地支、地支藏干、藏干十神、纳音五行。
五行能量图：木、火、土、金、水能量百分比分布与旺相休囚死状态。
日主解读：日主本元、日主自然物象特性、日主强弱评定、喜用神与忌神、幸运颜色、幸运方位、幸运数字。
第二页：性格深度分析 (4大类)
性格特质：3-5个核心关键词、3-5项具体性格优势、3-5项潜在劣势、五行十神成因。
思维方式：思维模式、决策风格、学习方式、表达方式。
情绪模式：情绪特点、主要压力来源、应对方式、落地调适建议。
依恋模式：感情依恋类型（安全/焦虑/回避/矛盾）、恋爱相处表现、核心情感需求、感情大忌雷区。
第三页：人生格局 (2大类)
命格定位：正统格局名称、通俗大白话含义、这一生的核心课题、命运层次评定。
人生阶段：童年(0-10岁)、少年(10-20岁)、青年(20-30岁)、壮年(30-40岁)、中年(40-50岁)、晚年(50岁+)对应大运干支与发展主题。
第四页：事业篇 (4大类)
事业方向：适合的5-10个具体行业、应避开的3-5个行业、适合岗位定位、体制内外建议、创业打工建议。
事业特质：3-5项职场优势、3-5项职场短板、适合带教的领导类型、团队角色定位。
事业运势时间线：当前大运吉凶与建议、下一步大运吉凶与准备、未来12个月逐季逐月关键窗口。
财富分析：终身财富层次、核心财富来源、最适求财方式、破财风险节点、实操理财配置原则。
第五页：感情篇 (3大类)
感情特质：感情类型风格、感情中的高光优点、感情中的扣分缺点、理想伴侣画像、不适合伴侣特征。
婚姻信息：早婚晚婚适龄建议、婚姻稳定性评定、正缘配偶外貌与性格特征、婚姻维系注意事项。
感情运势时间线：桃花最旺年份、最适结婚年份、感情低谷摩擦期、未来12个月感情走势研判。
第六页：健康篇 (2大类)
健康分析：体质偏向、终身需防范的脏腑病变方向、高风险大运流年、饮食作息运动建议。
健康细节：木（肝胆）、火（心脑）、土（脾胃）、金（肺系）、水（肾系）五大系统状态与保养清单。
第七页：流年流月 (3大类)
当前流年详细分析：流年干支、流年年度主题、事业运、财运、感情运、健康运、3-5条避坑注意事项。
未来12个月逐月运势：1月至12月完整表格（月份、干支、星级评分、事业、财运、感情、健康、具体建议）。
关键日期标注：年度核心吉日（日期+宜做事项）、年度关键凶日（日期+忌做事项）。
第八页：住宅风水 (1大类)
居住环境分析：适宜房屋坐向、九运风水格局、吉利方位、不利方位、家中财位、文昌学业位、桃花人缘位、5-10条现代居室软装调理建议。
第九页：心理认知 (2大类)
心理画像：现代心理学类型（MBTI/大五人格）、内在深层驱动力、核心恐惧、核心渴望、典型行为模式。
成长建议：个人升级突破方向、需克服的性格弱点、需放大的天赋优势、人际相处共赢法则、心态自我修复心法。
第十页：行动指南 (3大类)
综合建议：当前人生阶段定位、当前唯一核心任务、短期目标（3个月）、中期目标（1年）、长期目标（3-5年）。
禁忌事项：职业禁忌、投资禁忌、感情禁忌、健康禁忌。
幸运指南：幸运色、幸运方向、幸运数字、转运物品、大利行业、契合发展的标杆城市。

付费分级门控执行逻辑 (Tiered Gating Logic)
在渲染报告时，严格按照客户付费状态进行页面与模块过滤：
输入原始数据 -> 执行完整八字推演 -> 生成10页全量数据字典
                                         │
                   ┌─────────────────────┴─────────────────────┐
                   ▼                                           ▼
             【已解锁页面】                              【未解锁页面】
       全量渲染文字、表格、图表                   输出高转化锁定卡片 (Teaser Card)
       给出具体落地避险操作与时间线               包含痛点摘要、揭秘钩子、升级解锁指引
未解锁模块的遮罩模版：
> 🔒 【该模块内容已锁定】
> 推演引擎已完成针对您命盘的深度运算。如需解锁查看完整的《页面标题》及实战操作清单，请升级对应专项或全案版本。

执行流水线 (Step-by-Step SOP)
步骤一：数据校验与真太阳时计算
检验输入时间与八字干支的自洽性。若有出生地点，校正真太阳时。
步骤二：全量八字数理推演
提取日元五行能量比例，判定身强身弱与喜用忌神。
检索月令立格、十神透藏、大运顺逆与未来12个月流月干支。
结合现代心理学与职业赛道映射，组装全量数据字典。
步骤三：应用付费门控策略
检查 payment_tier，确定允许输出的页面集合。
步骤四：渲染并格式化交付
按照10页、29大类、120+项标准排版生成清晰美观的 Markdown 报告。

避坑要点与常见误区 (Gotchas)
绝对禁止向客户展示生硬难懂的玄学黑话（如“枭神夺食”、“伤官见官”），必须完全翻译为现实生活人话（如“思维内耗”、“因过于直率与直属领导顶牛”）。
绝不能因为客户选择基础版就不计算后8页。底座计算必须一次性完成，确保日后随时无损解锁。
12个月运势表必须完整列出12行，不能用省略号带过。
