# 西方心理占星 / 本命盘解读技能 (Western Psychological Astrology Skill)

> **体系**：西方热带黄道（Tropical Zodiac，春分点 0° 白羊）· 心理占星取向
> **宫位制**：Placidus（默认），亦可 Whole Sign / Equal House
> **蒸馏来源**：磁盘已有 `astro_transit`（行运）+ `astro_composite`（组合盘）能力卡 + 公版经典理论（四元素心理学、相位学、行运里程碑）
> **版权边界**：现代版权书（The Inner Sky / The Changing Sky / Astrology Karma & Transformation / Dynamics of the Unconscious / Synastry 等）**只蒸馏规则与断法，不放原书原文**。
> **版本**：v1.0 | 2026-09-15

## 1. 技能名称与描述

**western-astrology**：基于西方热带黄道的心理占星本命盘解读引擎。输入出生信息（或已排好的本命盘：太阳 / 月亮 / 上升、行星位置、宫位、相位），按心理占星取向输出元素 - 模态画像、行星 - 宫位 - 相位解读、行运（Transit）与次限推进（Secondary Progressions）时间主题、比较盘 / 组合盘双人互动分析。

本技能为**心理占星取向**：盘图是"自我认识与心理动力的隐喻镜子"，**非宿命论**——不预测具体事件、不下命运判决、不充当行为许可证。所有征象按"心理气候与季节"读取。

## 2. 触发条件

当用户提出以下需求时触发本技能：

- 提供出生日期 / 时间 / 地点，要求**西方本命盘 / 星盘**解读（明确说"西方占星""星座本命盘""natal chart"）
- 问**太阳 / 月亮 / 上升**组合的人格画像
- 问**行星相位**（合 / 冲 / 刑 / 三合 / 六合）的含义与心理动力
- 问**宫位**（十二宫生命领域）落星解读
- 问**行运 Transit**（"最近行运意味着什么""土星回归""水星逆行"）
- 问**次限推进 Secondary Progressions**（"我这几年为什么变了"）
- 问**比较盘 Synastry / 组合盘 Composite**（双人关系、合盘、"我们合不合"）
- 问**四元素 / 三模态**性格画像（火土风水 / 基本固定变动）

**不触发**：明确要吠陀 / 印度星盘（走 `vedic` 技能）、问八字 / 紫微 / 六爻、要求把西方盘度数翻译成吠陀星座（拒绝，坐标系隔离）。

## 4. 核心断法步骤

### Step 1：确定上升星座与宫位系统

- **上升星座（Ascendant / Rising）**：出生时东方地平线升起的星座，是人格面具、外在气质、与世界交手的方式；是整张盘的"门面"。
- **宫位系统**：默认 Placidus（分宫制，宫位大小不等）；若用户用 Whole Sign / Equal House 须声明，不混用。
- 行星落在**哪个宫**，决定该行星能量"在哪个生活领域"被体验。

### Step 2：行星入庙入曜落陷失势判定

- 判定每颗行星的 **dignity（尊严）**：入庙（Ruled）、曜升（Exalted）、落陷（Fall）、失势/游走（Detriment）。
- 现代心理占星**不把庙旺当"好"、落陷当"坏"**——尊严描述的是能量的**顺畅度 / 舒适度**，而非价值判断：落陷行星往往是心理成长的着力处。
- 外行星（天王 / 海王 / 冥王）世代共性强，个体解读落在其所落宫位与个人行星的相位上。

### Step 3：四元素与三模态心理画像

- **四元素**：火（火象：白羊/狮子/射手=热情、行动、直觉）、土（土象：金牛/处女/摩羯=务实、物质、结构）、风（风象：双子/天秤/水瓶=思维、社交、理念）、水（水象：巨蟹/天蝎/双鱼=情感、直觉、共鸣）。
- **三模态**：基本（Cardinal：白羊/巨蟹/天秤/摩羯=开创、启动）、固定（Fixed：金牛/狮子/天蝎/水瓶=稳定、坚持）、变动（Mutable：双子/处女/射手/双鱼=适应、灵活）。
- 数元素 / 模态的星群分布，出整体心理画像：缺某元素=该能量需刻意发展；某元素过盛=需平衡。

### Step 4：相位分析（合 / 冲 / 刑 / 三合 / 六合，容许度）

- **合相 0°**：融合、强化——两行星能量合一，色调由行星性质决定。
- **六合 60°**：机会、友善——轻松的潜力通道。
- **刑相 90°**：张力、摩擦——需要主动协调的拉力（成长着力点）。
- **三合 120°**：流动、和谐——顺畅的天赋通道。
- **对冲 180°**：极化、对立——两端拉扯，需整合（非"相克"）。
- **容许度（Orb）**：内行星紧密（约 8°），外行星宽松（约 5–6°）；相位越紧密影响越集中。
- 相位是"镜子的滤镜"，**不是行为许可证**：刑相≠可以发脾气，冲相≠必须分手。

### Step 5：宫位解读（十二宫生命领域）

按行星所落宫位定位"能量在哪个生活领域"：

| 宫 | 领域 | 宫 | 领域 |
|---|---|---|---|
| 1 宫 | 自我、外貌、气质 | 7 宫 | 伴侣、一对一关系 |
| 2 宫 | 价值、金钱、资源 | 8 宫 | 共享资源、转化、深度 |
| 3 宫 | 沟通、手足、近邻 | 9 宫 | 信念、远行、高等心智 |
| 4 宫 | 家庭、根基、内心安全 | 10 宫 | 事业、社会角色、公众形象 |
| 5 宫 | 创造、恋爱、子女、娱乐 | 11 宫 | 朋友、群体、愿景 |
| 6 宫 | 工作、健康、日常服务 | 12 宫 | 潜意识、隐秘、消融 |

### Step 6：行运 Transit 与次限推进 Secondary Progressions

- **行运 Transit**：当下天空行星与本命盘行星形成的相位，是"当下的心理气候"。
  - 内行星（月 / 水 / 金 / 火）：数日至数周，短期情绪主题。
  - 外行星（木 / 土 / 天 / 海 / 冥）：数月至数年，**人生季节**——木=扩张春、土=收敛冬、天=突破雷暴、海=溶解雾季、冥=深层重塑。
  - **里程碑行运**：土星回归（~29.5 岁，结构确立）、土星对冲（~15/44/74 岁，重评）、天王星对冲（~42 岁，中年环顾）。
- **次限推进 Secondary Progressions**：出生后一天=一年的象征推进，象征"内在成熟度的演化"，最著名的是**次限月亮**约 27.5 年走完一圈（情感需求的人生周期）。
- 行运 / 推进是"季节会换的气候"，**不预测具体事件**。

### Step 7：比较盘 Synastry 与组合盘 Composite 双人互动

- **比较盘 Synastry**：A 的行星与 B 的行星互相成相，像"两个乐手之间的化学反应"——看双方如何互相触发。
- **组合盘 Composite**：两人行星的数学中点构成一张**新盘**，是"关系本身"作为**第三实体**的盘——像"两人合奏出来的音乐"，不属于任何一方。
  - 组合太阳=关系的核心目的；组合月亮=关系的情感基调；日月和谐相=舒适与温情。
- 两人盘的定位：对话工具 / 关系镜子，**不预测关系成败**。

## 7. 注意事项与边界

1. **回归黄道 vs 恒星黄道**：本技能一律用热带黄道（春分点 0° 白羊），与吠陀恒星黄道差约 24°。**禁止**两体系混编 / 混译；用户用吠陀数据提问时先提示坐标系差异。
2. **心理占星非宿命论**：盘图是自我认识的隐喻镜子，**不预测具体事件**、不下命运判决、不充当行为许可证（刑相≠可发脾气，冲相≠必分手，土天行运≠灾难）。
3. **现代版权书只蒸馏规则不放原文**：The Inner Sky、The Changing Sky、Astrology Karma & Transformation、Dynamics of the Unconscious、Synastry 等现代版权著作，本技能只引用**蒸馏后的通用心理占星规则与断法**，不复制原书段落。
4. **外行星世代效应**：天王 / 海王 / 冥王同一代人共享星座，个体解读必须落到宫位与个人行星相位，而非"星座性格标签"。
5. **出生时间敏感**：上升与宫位对时间极敏感，须精确到分钟并做夏令时校正；时间不明则降权宫位 / 上升判断。
6. **比较盘 / 组合盘不判成败**：合盘是关系对话工具，不预测婚姻走向 / 出轨；出现家暴 / 控制信号时象征层让位安全评估。
7. **里程碑缓冲语必同步**：土星回归 / 天王星对冲等里程碑须同步反射"若已充实地活过，变化不会那么剧烈"的缓冲，拒绝剧本化（如"中年危机=必离婚"）。
8. **象征层只读**：置信带硬锁低区间，is_actionable 恒为 false；不构成医疗 / 法律 / 财务 / 婚恋决策依据。
