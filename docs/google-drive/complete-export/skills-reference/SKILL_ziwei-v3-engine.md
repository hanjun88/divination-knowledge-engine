Core Axioms and Constraints
置信度全局收敛：玄学类能力卡置信度严格锁定在 0.37 - 0.40 区间，严禁高于 0.40。
不可作为绝对行动依据：强制标记 is_actionable: false，所有推演结论作为文化参考与潜意识觉察透镜，禁止输出替代现实决策的指令。
去宿命化与心理学无损转译：彻底剥离旧时代克夫、克子、刑妻等宿命断语，1:1 映射为现代依恋理论 (ECR)、防御机制、关系边界与情绪调节问题。

Step-by-Step Inference Workflow
输入结构校验：验证命盘包含完整的命宫、夫妻宫、福德宫、迁移宫干支、十四主星、辅佐煞曜及生年/流年四化。
星曜相态评估：根据地支位置评估主星与煞曜的入庙、得地、平、陷状态，计算原始能级权重。
两邻与四正扫描：
检查夫妻宫前后两邻是否构成刑忌夹印、财荫夹印或羊陀夹忌。
检查三方四正对星是否齐聚，探测孤悬单星（辅弼/昌曲）的破缺触发。
能力卡规则匹配：
遍历 12 张 RIA++ 能力卡判定条件。
命中则构建 ASTProofNode，注入置信度与证据链。
UPIV V1.4 向量计算：
将命中的能力卡向量参数进行加权叠加。
输出六维连续值：情绪外化度、主导冲突防御、依恋焦虑 (1-10)、依恋回避 (1-10)、边界坚固度、主体性能动性。
跨引擎协同仲裁：
将紫微数据输入 CrossEngineArbitrator，与八字（理气）、西占（相位）、心理学（量表）并行仲裁。
执行 Top 3 CAP 截断合成，生成最终诊断报告与清醒舱指引。
Gotchas and Edge Cases
严禁孤立单星断命：凡推断必须兼顾三方四正与对宫，空宫必须借对宫主星并施加 0.80 折减系数。
煞曜并非全恶：入庙煞星（如午宫擎羊、辰戌贪狼火星）具备高度生产力，严禁直接判凶。
制化优先律：若见制化星曜（如天梁制化破军、紫微降七杀），破坏力大幅衰减，不可沿用原局凶断。
危机熔断原则：推演中若检测到严重自伤、自毁言辞，立即阻断命理推演，触发全国心理援助热线 12356 卡片。
