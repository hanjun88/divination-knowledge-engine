# 八字命理技能 (Bazi Mingli Skill)

> **底本**：《滴天髓阐微》（任铁樵注）、《命理约言》（陈素庵）、《造化元钥》（余春台）
> **核心方法**：任铁樵旺衰喜忌法 + 造化元钥调候用神法
> **版本**：v1.0 | 2026-09-15

---

## 1. 技能名称与描述

**bazi-mingli**：基于子平八字命理的命局分析引擎。输入一个完整八字（四柱、大运、性别），按任铁樵《滴天髓阐微》旺衰喜忌法，结合《造化元钥》调候用神表，输出日主旺衰、用神取定、格局判定、大运吉凶与人生趋向。

本技能以任铁樵"旺衰为体、喜忌为用"为骨架，《造化元钥》（穷通宝鉴）调候法为补充，陈素庵《命理约言》为正理校正。**反对**：不论日主衰旺专以财官为喜、奇格异局神煞妄谈、桃花咸池专论女命邪淫。

---

## 2. 触发条件

当用户提出以下需求时触发本技能：
- 提供一个八字四柱（年月日时干支），要求论命
- 问用神取法（"此造用神为何？"）
- 问大运吉凶（"这步运如何？"）
- 问格局判定（"此造是何格局？"）
- 问性格、事业、财运、婚姻、子女、寿元
- 问调候（"冬月生人宜何用神？"）
- 问从格/化格/专旺格真伪

**不触发**：仅问排八字（排盘由规则引擎 API 完成）、问六爻/紫微体系问题。

## 4. 核心断法步骤（从古籍编译的判定流程）

### 步骤 1：定日主与月令

- 以日干为日主（我）
- 以月令为提纲（定旺衰第一义）
- 查日主在月令的旺相休囚死：
  - 同我者旺（月支同日主五行/比和）
  - 我生者相（月令生日主）
  - 生我者休（日主生月令）
  - 克我者囚（月令克日主）
  - 我克者死（日主克月令）

### 步骤 2：察日主旺衰

[任氏曰]"子平之法，全在四柱五行。察其衰旺，究其顺悖，审其进退，论其喜忌"

**旺衰判定要素**：
1. 日主是否得令（月令同气/生扶）
2. 日主是否得地（地支通根禄旺）
3. 日主是否得势（天干比劫印绶多寡）
4. 四柱生克关系（官杀食伤财印比劫分布）

**旺衰分级**：
- 太旺/从旺：日主极旺，满局比劫印绶，不见官杀
- 旺：日主得令得地得势
- 中和：日主不旺不衰
- 弱：日主失令失地失势
- 太弱/从弱：日主极弱，满局克泄耗，不见生扶

### 步骤 3：取用神

[任氏曰]"命中至理，只存用神，不拘财官印绶比劫食伤枭杀，皆可为用，勿以名之美者为佳，恶者为憎"

**用神取法**：
- 日主旺 → 取克泄耗为用（官杀/食伤/财星）
- 日主弱 → 取生扶为用（印绶/比劫）
- 日主旺极 → 顺其气势，取泄/顺为用（从旺格，反忌克）
- 日主弱极 → 顺其气势，取克泄耗为用（从弱格，反忌生扶）
- 调候为急 → 冬月用火暖、夏月用水润（见 tiaohou_matrix.md）

**忌神**：克用神之神
**喜神**：生用神之神
**仇神**：克喜神生忌神之神

### 步骤 4：辨格局

**正格（八格）**：
- 身强：正官格、七杀格（制化得宜）、正财格、偏财格、食神格、伤官格
- 身弱：正印格、偏印格（枭神）、建禄格、月劫格

**特殊格局（须真方可）**：
- 从格：从财、从官杀、从儿（食伤）、从势（满局克泄耗无生扶）
- 化格：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火（须真化得令）
- 专旺格：曲直（木）、炎上（火）、稼穑（土）、从革（金）、润下（水）——一方独旺不杂克
- 两神成象：水火既济、木火通明、金白水清等

**任氏辟谬**：
- 不执"甲木为梁栋、乙木为花果、丙作太阳、丁作灯烛"等物象拟人
- 不执"财可养命、官可荣身"——不用财星尽可劫，不用官星尽可伤
- 奇格异局神煞纳音"乃好事妄造，非关命理休咎"

### 步骤 5：论四柱配合

[任氏曰]"配合干支，必须正理搜寻详推，与衰旺喜忌之理"

**配合原则**：
1. 天干地支相为配合，仔细推详进退之机
2. 四柱生化有情，五行不争不妒为吉
3. 有病得药为贵——"有病方为贵，无伤不是奇"
4. 冲会有彼我之分：喜神是我，忌神为彼；宁可我去冲彼，不可彼来冲我
5. 不可我去冲彼=冲起；彼来冲我=不起

### 步骤 6：大运吉凶

**大运顺逆规则**：
- 阳男阴女：顺排
- 阴男阳女：逆排
- 依月柱起运，十年一运

**大运吉凶判定**：
1. 运干与运支同看，不可偏废
2. 运扶用神/喜神为吉运
3. 运扶忌神/仇神为凶运
4. 命局有病，运去其病为药——"如人染沉疴，得良剂以生也，不贵亦富"
5. 命局无病，运破用神为祸
6. 从格运背则祸，化格运破则凶

### 步骤 7：人生趋向推断

依用神喜忌与大运走向：

| 用神 | 趋向 |
|---|---|
| 官杀 | 功名、官职、规矩、压力 |
| 印绶 | 学业、长辈、庇荫、文名 |
| 比劫 | 兄弟、朋友、竞争、财散 |
| 食伤 | 才华、技艺、子女、财源 |
| 财星 | 财富、妻子、物质、欲望 |

**五行性情**：
- 木主仁：慈悲恻隐，曲直俯仰
- 火主礼：礼让光明，急躁急速
- 土主信：诚信敦厚，厚重载物
- 金主义：义气果决，刚毅肃杀
- 水主智：智慧灵动，多变流转

## 7. 注意事项与边界

1. **旺衰第一义**：不论财官名美恶，只看日主衰旺与用神喜忌。"用之为财不可劫，用之为官不可伤"——其要在一"用"字。
2. **辟物象拟人**：不执"甲木梁栋、乙木花果、丙火太阳、丁火灯烛"等拟人之说。
3. **辟神煞纳音**：桃花咸池专论女命邪淫、金锁铁蛇谬指小儿关煞，"荒唐取用"。
4. **从格须真**：从财从杀从儿，须满局无一点生扶；微根即不从。
5. **化格须真**：化神得令、四柱不逆，方论真化。
6. **冲会有彼我**：喜神是我忌神为彼，宁可我去冲彼（冲起），不可彼来冲我（不起）。
7. **大运为重**："命之所重在运，运其可忽乎？人有凌云志，无运不能自达也。"
8. **有病方为贵**：四柱无全美，有病得药为贵格；无病无药反主平庸。
9. **调候为急**：冬月生人火为急，夏月生人水为急；调候用神重于扶抑用神。
10. **不可执一**："局混方兮有纯疵，行运喜南或喜北"，须看局中意向。
