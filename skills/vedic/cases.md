# 吠陀占星经典格局判例集 (Vedic Casebook)

> 体系：Parashari 吠陀占星 · Lahiri 恒星黄道 · 整宫制（Whole Sign）
> 每条含：盘式配置（Lagna / 行星位置 / Dasha）、格局名称、断语、应期 / 验证、出处标注。
> 立场：以下均为"自我观察的隐喻镜像"，非宿命判决；应期为传统理论推演示例，非实测预言。
> 公版出处：BPHS（Brihat Parashara Hora Shastra）、Jaimini Sutras 为古典梵文典籍，核心概念属公版。

---

## V01 · Gajakesari Yoga（象狮瑜伽）

- **盘式配置**：Lagna 任意；Chandra（月亮）在 Karka（巨蟹），Guru（木星）在 Meena（双鱼）——月木相隔第 7 宫（角位互照）。
- **格局名称**：Gajakesari Yoga（Chandra 与 Guru 居角位 1/4/7/10）。
- **断语**：传统读作心智清明、德行受敬重、心思稳重而有智慧引导的象征；月木互照如"象与狮"并立，情绪有智慧托底。镜像读法：你的情绪潮汐（月）容易被一种扩张 / 信念 / 导师感（木）托住。
- **应期 / 验证**：Guru Mahadasha 或 Guru  Antardasha 期间，此瑜伽被点亮，智慧 / 教导 / 信念类主题被激活。
- **出处**：[BPHS·Yoga 章·Gajakesari]。

## V02 · Raja Yoga（王瑜伽 · 角主 + 三角主关联）

- **盘式配置**：Lagna 为 Mesha（白羊）；Lagnesha（火星）在第 1 宫，同时第 5 宫主（Surya 太阳）与火星互照 / 同宫。
- **格局名称**：Raja Yoga（角宫主 1/4/7/10 与三角宫主 1/5/9 关联）。
- **断语**：前现代称"王瑜伽"，现代化读作**自主与责任的结合**——一面关于领导力模式的镜子，不等于必为领袖。角主给行动场，三角主给法（dharma）与创造，二者合流则"做自己想做且该做的事"。
- **应期 / 验证**：Lagnesha 或三角主之 Dasha 期间，自主 / 领导 / 责任主题被点亮。
- **出处**：[BPHS·Yoga 章·Raja Yoga]；[Jaimini Sutras·Karaka 章]。

## V03 · Dhana Yoga（财富瑜伽）

- **盘式配置**：Lagna 为 Vrishabha（金牛）；第 2 宫主（Shukra 金星）与第 5 宫主（Budha 水星）在第 11 宫会合。
- **格局名称**：Dhana Yoga（资源宫 2/11 主与三角 / 角宫主关联）。
- **断语**：读作**资源流动顺畅**的意象——积累（2 宫）与收益（11 宫）经由创造 / 智慧（5 宫）打通。非"暴富判决"，而是"资源管道通畅"的隐喻。
- **应期 / 验证**：Shukra 或 Budha 的 Mahadasha / Antardasha 期间，资源 / 收益主题被点亮。
- **出处**：[BPHS·Yoga 章·Dhana Yoga]。

## V04 · Budha-Aditya Yoga（水日合）

- **盘式配置**：Lagna 任意；Surya（太阳）与 Budha（水星）同 Rashi 同宫（通常在 Kanya 室女 / Simha 狮子）。
- **格局名称**：Budha-Aditya Yoga（水日合相）。
- **断语**：自我 / 权威（日）与智力 / 言语（水）合一，传统读作头脑清晰、辩才、善于分析与表达。镜像读法：你的"我是谁"（日）和你"怎么想怎么说"（水）是同频的。
- **应期 / 验证**：Budha 大运期间，思维 / 沟通 / 商业 / 技能主题被点亮。
- **出处**：[BPHS·Yoga 章·Budha-Aditya]。

## V05 · Pancha Mahapurusha · Hamsa Yoga（木星大人瑜伽）

- **盘式配置**：Lagna 为 Karka（巨蟹）；Guru（木星）在 own sign Meena（双鱼）居第 9 三角宫 / 或角宫。
- **格局名称**：Hamsa Yoga（Guru 在 own/exalt 且居角宫 1/4/7/10，五大人人格瑜伽之一）。
- **断语**：Guru 有力且在角宫，传统读作智慧、正直、受人尊崇、有福报之人。现代化：你的信念 / 意义感（木）落在人生舞台（角宫），容易成为他人的导师或榜样。
- **应期 / 验证**：Guru 大运 / 木星过 Lagna 或第 9 宫期间，信念扩张与被认可主题浮现。
- **出处**：[BPHS·Yoga 章·Pancha Mahapurusha · Hamsa]。

## V06 · Pancha Mahapurusha · Ruchaka Yoga（火星大人瑜伽）

- **盘式配置**：Lagna 为 Vrischika（天蝎）；Mangala（火星）在 own sign Mesha（白羊）居第 5 宫 / 或角宫。
- **格局名称**：Ruchaka Yoga（Mangala 在 own/exalt 且居角宫，五大人人格瑜伽之一）。
- **断语**：火星有力且在角宫，传统读作勇敢、有执行力、武勇、体魄强健。镜像读法：你的行动 / 勇气（火）有稳固的人生舞台支撑，行动不拖泥带水。
- **应期 / 验证**：Mangla 大运或火星行运（Gochara）过本命火星期间，行动力 / 竞争 / 开创主题被点亮。
- **出处**：[BPHS·Yoga 章·Pancha Mahapurusha · Ruchaka]。

## V07 · Vargottama Graha（D1=D9 同座 · 内外一致）

- **盘式配置**：Lagna 为 Simha（狮子）；Surya 在 D1 落 Simha 第 1 宫，在 D9 Navamsha 仍落 Simha。
- **格局名称**：Vargottama（同一 Graha 在 D1 与 D9 同 Rashi）。
- **断语**：D1 是花、D9 是果；同一 Graha 两盘同座，传统读作该 Graha 力量"内外一致、成熟稳定"，不因 D9 折损。镜像读法：你外在展现的 X，内在骨架支撑的也是 X——"表里如一"的那个面向。
- **应期 / 验证**：该 Graha 的 Dasha 期间，其主题因内外一致而更稳定、更可持续。
- **出处**：[BPHS·Navamsha 章]；[BPHS·Varga 章·Vargottama]。

## V08 · Neecha Bhanga Raja Yoga（落陷取消 · 反向成贵）

- **盘式配置**：Lagna 为 Vrischika（天蝎）；Shukra（金星）在 Neecha 落陷 Kanya（室女），但落陷星座的主宰星（Budha）在角宫得势，且 Shukra 主宰角宫 / 三角宫。
- **格局名称**：Neecha Bhanga Raja Yoga（落陷被取消，并升格为王瑜伽）。
- **断语**：落陷 Graha 的弱点被其主宰星的有力位置"挽救"，传统读作"先抑后扬、困境中反成"。镜像读法：某个原本偏弱的面向（如金星落陷=价值感 / 愉悦感别扭），经由其主宰星的支撑，反而成为独特的成长张力。
- **应期 / 验证**：落陷 Graha 之 Dasha 初期显"别扭"，其主宰星 Antardasha 期或之后转为"反向成长"。
- **出处**：[BPHS·Yoga 章·Neecha Bhanga]。

## V09 · Kemadruma Yoga（月两侧空 · 孤悬）

- **盘式配置**：Lagna 任意；Chandra（月亮）所在宫的**前后两宫（第 2、第 12 宫相对月）无任何 Graha**，且月不与任何 Graha 会合 / 互照。
- **格局名称**：Kemadruma Yoga（月亮两侧无行星）。
- **断语**：传统旧说偏凶（孤立、情绪无依）；现代镜像读作**情绪上的独立 / 自给自足**——月亮缺乏其他行星"托底"，情绪节奏更自走、少受外界牵引。不可渲染为"孤苦命"。
- **应期 / 验证**：Chandra 大运期间，情绪 / 安全感主题被点亮，需主动建立情绪支持网络（现实层面，非盘上）。
- **出处**：[BPHS·Yoga 章·Kemadruma]。

## V10 · Parivartana Yoga（交换瑜伽 · 互主）

- **盘式配置**：Lagna 为 Mithuna（双子）；Budha（水星，守第 1 与第 4 宫）落 Vrishabha（金星守），Shukra（金星）落 Mithuna（水星守）——二 Graha 互换宫位主宰。
- **格局名称**：Parivartana Yoga（两 Graha 互换主宰宫位）。
- **断语**：双向交换形成稳定结构，传统读作两个生活领域（此处为自我 / 心智 与 家庭 / 舒适）之间资源互通、互为后门。镜像读法：你"怎么想"（水）和你"要什么价值 / 舒适"（金）互相为对方开门。
- **应期 / 验证**：Budha 或 Shukra 大运期间，两个互换领域的联动被激活。
- **出处**：[BPHS·Yoga 章·Parivartana]。

## V11 · D9 第七宫验证婚姻骨架（D1 花 / D9 果）

- **盘式配置**：Lagna 为 Vrishabha（金牛）；D1 第 7 宫（Tula 天秤）有 Shukra 入庙看似吉；但 D9 Navamsha 第 7 宫为 Vrischika，Ketu 落于此。
- **格局名称**：D1 吉而 D9 折（D1 花美 / D9 果涩）。
- **断语**：D1 第 7 宫金星入庙，外在关系场看似和谐；但 D9 第 7 宫 Ketu（出离 / 切断）提示关系的"内在骨架"里有一种疏离 / 抽离的色调。镜像读法：你外在展现的关系状态（D1），和内在真正想要的关系骨架（D9）**不一致**——问自己"我外在要的关系和我内在要的，是不是一回事"。
- **应期 / 验证**：Shukra / Ketu 相关 Dasha 期间，关系中"亲密 vs 抽离"的张力被点亮。**禁止**据此判婚姻成败。
- **出处**：[BPHS·Navamsha 章]；[BPHS·Ketu 章]。

## V12 · Janma Nakshatra 定 Dasha 起点（Pushya 宿）

- **盘式配置**：Lagna 任意；出生时月亮在 Pushya 宿（Pushya 由 Shani 土星主掌），Pada 2。
- **格局名称**：Janma Nakshatra = Pushya（生宿定 Dasha 起点示例）。
- **断语**：Pushya 传统读作"滋养 / 吉祥 / 滋养者"，是月亮较受偏爱的宿之一；镜像读法：你的情绪潮汐（月）更偏"滋养、照顾、可靠"的色调。因 Pushya 由 Shani 主掌，Vimshottari Dasha 从 Shani 大运起算。
- **应期 / 验证**：出生即起 Shani 大运（起点剩余年数按 Pada 精确计算）；Shani 大运主题为纪律 / 延迟 / 长期结构，非"凶运"。
- **出处**：[BPHS·Nakshatra 章]；[BPHS·Dasha 章·Vimshottari]。
