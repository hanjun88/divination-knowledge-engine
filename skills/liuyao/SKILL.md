# 六爻断卦技能 (Liuyao Divination Skill)

> **底本**：《增删卜易》（野鹤老人）、《卜筮正宗》（王洪绪）、《黄金策》（刘伯温）、《易隐》（曹九锡）
> **编译依据**：`六爻决策树编译.md`（84 条 IF-THEN 规则、41 条权值、8 个状态节点）
> **版本**：v1.0 | 2026-09-15

---

## 1. 技能名称与描述

**liuyao-divination**：基于纳甲筮法的六爻断卦引擎。输入一个完整卦象（含月建、日辰、六爻动变、六亲六神），按野鹤老人经验派规则输出吉凶、应期与关键救应。

本技能以《增删卜易》经验派为骨架，《卜筮正宗》十八论为规则校正，《黄金策·总断千金赋》为义理母本。凡四本分歧处，以"经占验修正"者（野鹤）为准。

---

## 2. 触发条件

当用户提出以下需求时触发本技能：
- 提供一个已排好的六爻卦象（含年月日辰、动爻、变爻），要求断吉凶
- 占问具体事项：功名/求财/婚姻/疾病/行人/出行/官司/失物/家宅/风水
- 问应期（"何时成/何时败/何日应"）
- 要求对比多卦合参（再占法）
- 问某爻旺衰、用神取法、伏神飞神

**不触发**：仅问卦理概念、要求排卦（排卦由规则引擎 API 完成）、问紫微/八字体系问题。

## 4. 核心断法步骤（从古籍编译的判定流程）

### 步骤 1：取用神（取用）

按所占事类取用神 [增删·卷一·用神章第八]：

| 事类 | 用神 | 原神 | 忌神 |
|---|---|---|---|
| 功名/官禄 | 官鬼爻 | 妻财 | 子孙 |
| 求财/贸易 | 妻财爻 | 子孙 | 兄弟 |
| 父母/长辈/文书 | 父母爻 | 妻财 | 子孙 |
| 兄弟/同辈 | 兄弟爻 | 父母 | 妻财 |
| 子女/下属/医药 | 子孙爻 | 兄弟 | 父母 |
| 妻妾/夫 | 男占妻=妻财；女占夫=官鬼 | — | — |
| 家宅/风水 | 以父母为宅、世爻为人 | — | — |
| 自身/身命 | 世爻 | 原神 | 忌神 |

**用神两现** [增删·卷二·两现章第三十二]：
- 古法：舍休囚用旺相、舍静用动、舍破用不破、舍空用不空、舍伤用不伤
- 野鹤修正：多有应于旬空月破者，可舍不空而用空、舍不破而用破（须合前卦）

**用神不现** [增删·卷二·飞伏章第二十八]：
- 寻本宫首卦伏神；飞神空破休囚墓绝则伏神易出
- 野鹤秘法：再占一卦，用神必现（不必强寻伏神）

### 步骤 2：定四神

- 原神 = 生用神之爻
- 忌神 = 克用神之爻
- 仇神 = 克原神、生忌神之爻

### 步骤 3：月破旬空状态机

**月破**（月建冲爻）[增删·卷二·月破章第二十七]：
- 静而不动、又无日辰动爻生助 → 真破（到底破）
- 动而月破 / 得生扶 → 待实之破（出月/填实/逢合方解）
- 爻临日建虽月破 → "破而不破"

**旬空** [增删·卷一·旬空章第二十六]：
- 旺相 / 发动 / 得日辰动爻生扶 / 动而化空 / 伏而旺相 → 假空（出旬有用）
- 月破 / 有气不动又被克 / 伏而被克 / 春土夏金秋木冬火 → 真空（到底空）
- 日辰冲空 → 冲空则实

**叠加** [综合四本]：
- 真破+真空 → 最凶，到底无用
- 月破+旬空但发动/得生扶 → 双填之期应事

### 步骤 4：动静分类

[增删·卷一·动变章第七][暗动章第二十二][动散章第二十三]：
- 明动爻：老阳○/老阴×发动，动而必变
- 暗动：静爻旺相被日辰冲，按动爻计
- 日破：静爻休囚被日辰冲，更加无用
- 动散：动爻被冲（休囚方论，旺动不散）
- 独发/独静：仍以用神为主，不可执独发断吉凶

### 步骤 5：旺衰加权

综合权值（月建>日辰>动爻>变爻>静爻）[增删·卷一·日辰章]：

```
score = 月建权值 + 日辰权值 + 动爻群权值 + 变爻回照权值
```

**修正铁律**：
1. 寡不敌众：临月建/日辰之爻，若卦中动爻成群克之，"双拳不敌四手"
2. 用神无根：月破+日克，"值月破而被克，虽有生扶之不起，如树无根"

分级：
- score ≥ 4：太旺/旺相（喜墓库收藏，应期逢墓逢冲）
- score ≥ 1：有气/旺
- score ≥ -1：中和/平
- score ≥ -3：休囚/衰
- score < -3：无气/极弱

### 步骤 6：四神联动

[增删·卷一·元神忌神衰旺章第十]

**原神有力**（五条件任一）：
1. 旺相/临日月/动爻生扶
2. 动化回头生/化进神
3. 长生/帝旺于日辰
4. 与忌神同动（贪生忘克）
5. 旺动临空化空

**原神无力**（六条件任一）：休囚不动/休囚又被伤/逢旬空月破/化退神/衰绝/入三墓/化绝化克化破化散

**忌神有力**（五条件任一）：旺相/临日月/动化回头生/化进神/旺动临空化空/长生帝旺于日辰/与仇神同动

**忌神无力**（七条件任一）：休囚不动/静临空破/入三墓/化退神/衰绝/化绝化克化破化散/与原神同动（贪生忘克）

### 步骤 7：生克路线裁决

[增删·卷一·动静生克冲合章第十五]

```
第1级：月建、日辰（如天，能生克一切爻）
第2级：动爻（明动+暗动，动能克静）
第3级：变爻（仅对本位动爻回照）
第4级：静爻（仅旺相静爻可生克休囚静爻）
```

**介入修正**：
- 贪生忘克/贪合忘冲：动爻若旁逢生合，则忘克忘冲
- 三合局成局时以局代单爻论生克
- 合绊：动逢合=绊住（-1）；静逢合=合起（+1）

### 步骤 8：吉凶总判

```
净 = score + 生克净值 + (原神有力?+2:0) + (忌神有力?-2:0)

净 ≥ 4  → 大吉，事必成
净 ≥ 1  → 小吉，待时可成
净 ≥ -1 → 平，参详事类
净 ≥ -3 → 凶，避之为吉
净 < -3 → 大凶，有救方解
```

### 步骤 9：应期推断

[增删·卷一·各门类应期总注]

| 用神状态 | 应期推断 |
|---|---|
| 静而不动 | 逢值逢冲之日月 |
| 发动 | 逢合逢值之日月 |
| 太旺 | 逢墓逢冲之日 |
| 衰绝 | 遇生遇旺之月日 |
| 入三墓 | 冲开墓库之日 |
| 逢合住 | 冲开合神之日 |
| 月破 | 填实/逢合之期 |
| 旬空 | 填冲（出旬值日/日冲空）之期 |
| 化进神 | 逢值逢合之期 |
| 化退神 | 忌值忌冲之期退尽方应 |
| 世空原神动 | 待原神逢值之期 |
| 远近分野 | 远事定年月，近事应日时 |

## 7. 注意事项与边界

1. **六神权重轻**：青龙朱雀等仅作性情描述，权重轻于五行六亲，不可凭六神定吉凶。[增删·卷一·六神章]
2. **神煞无独立权值**：贵人禄马天医等"临吉则吉、临凶则凶"，不单独赋权。[正宗·卷三·辨谬诸篇]
3. **卦身/世身/本命不用**：正宗辟世身之谬，增删弃卦身不用。[正宗·卷三·辟卜筮全书世身之谬]
4. **六害删而不用**：增删明言"全无应验，删之"。[增删·卷一·六害章]
5. **多占法**：卦不分明时，次日再占一卦合决之，不可妄断。一事一刻不可连占；事急者歇歇又占。
6. **代占规则**：功名须亲占，代占难取用神。疾病可一家代占。
7. **太岁**：仅主一年之事，"宜静不宜动"，不列入日常月日旺衰权值。
8. **盲占禁忌**：不可心怀两事而占，一念之诚则应。占此而应彼、占远而应近，须细察。
