Shenshi Xuankong Feng Shui Analysis
《沈氏玄空学》（沈竹礽著）乃近代玄空风水学集大成之作。其核心宗旨以“三元九运”为时间坐标，以“二十四山”为空间坐标，以“洛书九宫飞星”为数理推演工具，配合“峦头形局”推断阳宅与阴宅之丁财贵贱、吉凶祸福及发应时限。
When to Use
阳宅或阴宅玄空飞星排盘（下卦与兼向替卦排盘）
判定命局九宫格局（旺山旺向、双星到向、双星到坐、上山下水）
识别玄空特殊格局（反吟伏吟、父母三般卦、连珠三般卦、合十局、令星入囚、城门诀）
结合紫白九星五行生克与组合断诀（如一四同宫、二五交加、三七叠至、七九穿心等）断定人事物祸福
形理兼察：结合峦头（内外六事、砂水形势）进行风水选址、户型诊断与趋吉避凶调理
Core Principles
1. 三元九运与九星性情
上元：
一运（一白贪狼，坎卦，属水，主文贵、中男）
二运（二黑巨门，坤卦，属土，为病符、老母）
三运（三碧禄存，震卦，属木，为蚩尤是非星、长男）
中元：
四运（四绿文曲，巽卦，属木，主文昌、长女）
五运（五黄廉贞，中宫，属土，为正关煞、大病灾）
六运（六白武曲，乾卦，属金，为官星、老父）
下元：
七运（七赤破军，兑卦，属金，为贼星、少女）
八运（八白左辅，艮卦，属土，为财星、少男）
九运（九紫右弼，离火，属火，为喜庆桃花、中女）
旺衰通则：
当令为旺气，紧随其后者为生气，再后者为退气、衰气、死气、煞气。

坎卦：壬（地，阳）、子（天，阴）、癸（人，阴）
艮卦：丑（地，阴）、艮（天，阳）、寅（人，阳）

3. 排盘推演机制
立运盘：当令运星入中宫，按洛书数序一律顺飞八宫，定各宫运星。
定山向星：
查坐山所在宫位的运星，以该运星为山星入中，写于中宫左上角。
查向首所在宫位的运星，以该运星为向星入中，写于中宫右上角。
辨顺飞与逆飞：
查中宫山星/向星在洛书原旦盘对应的本宫。
视坐山/向首属于哪一元龙（天元、地元或人元），寻原旦盘本宫同元龙之山的阴阳。
逢阳顺飞，逢阴逆飞；顺逆依洛书轨迹排布八宫。
起星替卦（兼向超过3度或逢出卦出位）：
替卦口诀：
子癸并甲申，贪狼一路行（子癸甲申用一白）
壬卯乙未坤，五位为巨门（壬卯乙未坤用二黑）
乾亥辰巽巳，连戌武曲位（乾亥辰巽巳戌用六白）
酉辛丑艮丙，七曜破军星（酉辛丑艮丙用七赤）
寅午庚丁上，右弼四星临（寅午庚丁用九紫）
替得之星入中，再依原元龙山向在替换前宫位的阴阳属性定顺飞逆飞。
4. 四大格局与峦头形理配合
玄空秘诀：“山上龙神不下水，水里龙神不上山”。
旺山旺向（到山到向）：
当令山星到坐山，当令向星到向首。
峦头配合：坐后宜有高山/实墙，向前宜有秀水/明堂/平地。主丁财两旺。
双星会向（双星到向）：
当令山星与向星皆飞临向首宫位。
峦头配合：向首需有水，水外有山（城门外有案山）或有近水远山。主旺财，若无山则损丁。
双星会坐（双星到坐）：
当令山星与向星皆飞临坐山宫位。
峦头配合：坐后需有小水池或空地，水外又有高山秀峰。主旺丁，若无水则破财。
上山下水：
当令山星飞到向首，当令向星飞到坐山。
峦头配合：正常平阳环境主丁财两败；除非遇“颠山倒水”地貌（坐后有低水、向前有高山）反可化凶为吉。
5. 特殊格局
反吟与伏吟：
山星或向星排布与洛书元旦盘完全相同为伏吟；完全相对相冲（如一入九、二入八）为反吟。
最忌当令五黄入中，或五黄飞临之宫山向重叠，主大病、横祸、破产。
父母三般卦与连珠三般卦：
父母三般卦：各宫山、向、运三星皆构成一四七、二五八、三六九组合，通气化解煞气，主富贵悠久。\n  - 连珠三般卦：各宫三星呈一二三、二三四等连续数，主通泰平安。
合十局：
全盘运星与山星、运星与向星、或向星与山星相加为十。主全局气场通畅，得贵人相助，逢凶化吉。
城门诀：
向首两旁之卦为城门。须运星入中后，城门飞临之向星为当令旺星，且与向首同元一气，方为正城门可用。主开门引动旺气，速发横财。
令星入囚：
当令向星或山星飞入中宫，称为入囚。入囚之运，原局气绝，家运败落，除非中宫开天井见光放气。
6. 紫白组合生克断诀
一四同宫：文曲齐会，科甲联名，利学业、文章、官位。
一六共宗：水清金白，主智慧、官运、名利双收。
二五交加：二黑逢五黄，兼逢土旺，必损主，主癌症、恶疾、破家亡身。
三七叠至：三碧木遇七赤金，为贼匪官非，盗贼侵扰，伤残手足。
六七交剑：乾兑相争，兵刃刀剑之伤，官司口舌，父女不睦。
七九合辙：七赤兑金与九紫离火相激，回禄之灾（火灾），血光口舌。
二三斗牛煞：二黑坤土与三碧震木相争，地天交战，官非口舌，母子不和。
八九庆会：辅弼相生，喜事重重，田产丰饶，丁财兼备。
Step-by-Step Analysis Workflow
立极定向：
确定房屋建造及入住的时间以定元运（如2004-2023为八运，2024-2043为九运）。
测定房屋坐向度数，明辨罗盘二十四山分金，核对是否在正线还是兼向（兼线超过3度需起替卦，遇空亡线主怪异破败）。
布列九宫飞星：
起运盘排定八宫。
寻坐向运星入中，依元龙阴阳布算山盘与向盘顺逆飞星。
定局辨体：
审视是否属于四大基本格局（旺山旺向、双星到向、双星到坐、上山下水）。
筛查反吟、伏吟、令星入囚、三般卦、合十、暗拱等特殊格局。
形理互参（峦头与理气印证）：
外六事：勘察外部真山真水、道路、高楼、桥梁、尖角冲煞，核实山水是否落在对应山向吉位。
内六事：大门（气口）、主卧、厨房炉灶、动线通道、神位、卫生间所处宫位的山向星组合。
断吉凶与流年应期：
结合各宫坐向飞星的生克衰旺与紫白克应断定人丁与财富。
以流年、流月九星入中飞临各宫，配合冲起、引动、到位的法则推断吉凶发应年份与月份。
风水调理与布局建议：
避开与化解二黑病符、五黄大煞（宜金化土，忌红与火生旺）。
催旺当令旺星与一白、六白、八白、九紫吉星（摆放真水、动水、绿植、安床开门）。
Gotchas
绝不可离开峦头空谈理气：“峦头无理气不灵，理气无峦头不验”。理气再吉，若门前见尖角反弓冲煞，依然招灾。
兼卦与下卦界限分明：各山正中正负4.5度范围内按下卦论；超出3度到4.5度之间以及跨卦界限，必须严格使用替卦起星诀。
上山下水并非皆主大凶：遇颠山倒水之地形（背后有真水实流，前面有昂然高山），反而转凶为大富大贵之局。
五黄中宫逢生则祸大：五黄廉贞为皇极中土，动则生灾，忌在五黄流年或五黄坐向处动土修造。
