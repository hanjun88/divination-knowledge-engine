## W01 · 太阳狮子 4 宫 + 月亮巨蟹 3 宫（日月同属火水）

- **配置**：太阳 Leo H4；月亮 Cancer H3；上升 Virgo。
- **解读要点**：太阳 4 宫=核心身份围绕家庭 / 内在安全 / 根基；月亮巨蟹 3 宫=情感需求通过日常沟通、手足、近距离交流获得安全感。日月分别在火 / 水象，身份热情外显而情感黏着向内。
- **心理画像**：一个把"家"当舞台中心的人——外在以服务 / 分析（上升处女）示人，内核渴望被需要与被滋养。情感安全感建立在"有话可说、有人可念"上。
- **出处**：[四元素心理学 · 火水]；[宫位心理学 · 4宫/3宫]。

## W02 · 太阳刑月亮（Sun square Moon）内在张力轴

- **配置**：太阳 Leo H4（火）与月亮 Taurus H8（土）成 90° 刑相，容许度 3°。
- **解读要点**：太阳刑月=核心身份（我想成为谁）与情感需求（我需要什么）持续拉扯，是心理占星经典的"内在张力轴"。火象的戏剧化自我表达 vs 土象的稳重占有欲，需终生整合而非二选一。
- **心理画像**：常在"想张扬自己"与"想守安全感"之间摆动。这不是缺陷，而是主动协调的成长着力点——张力不解决，只整合。
- **出处**：[相位象征光谱 · 刑相 90° 张力]。

## W03 · 金星拱木星（Venus trine Jupiter）天赋通道

- **配置**：Venus Cancer H3 与 Jupiter Scorpio H7 成 120° 三合，容许度 1°。
- **解读要点**：三合=流动、和谐的天赋通道。金星（爱 / 价值）与木星（扩张 / 信念）三合，象征关系与价值观领域自带"好运 / 慷慨"色调——容易在关系中被滋养，也容易过度乐观。
- **心理画像**：在关系和价值判断上天生顺遂、大方；需警觉"坐享好运而不充分利用"的倾向（外行星行运卡的缓冲语）。
- **出处**：[相位象征光谱 · 三合 120° 流动]；[外行星生命周期 · 木星扩张]。

## W04 · 土星合太阳（Saturn conjunct Sun）· 成年结构季

- **配置**：本命 Saturn Capricorn H9 合本命 Sun Cancer H4？——以行运示例：行运 Saturn conjunct 本命 Sun。
- **解读要点**：土星合太阳（行运）象征"多年努力的顶点与朝着目标奋斗的结晶"，土星把责任与辛苦施加于"对你最重要的事物"（太阳=身份 / 自我）。像冬天的收成与盘点。
- **心理画像**：这个阶段身份感被严肃化——不是"完了"，而是"收成与盘点"。过去踏实努力者得认可；偏离责任者冬天更冷。季节会换。
- **出处**：[外行星生命周期 · 土星如冬]。

## W05 · 土星回归（Saturn Return）~29.5 岁

- **配置**：行运 Saturn 回到本命 Saturn 位置（约 29.5–30.5 岁发生，三重合三次）。
- **解读要点**：西方占星的人生时钟刻度——成年期结构的确立。被象征为"第一次被要求为自己的人生真正负责"，常伴随职业 / 关系 / 居住的结构性决断。
- **心理画像**：不是灾难，是"成年礼"的镜像。问自己：我建立的结构是我要的吗？季节在冬春之交。
- **出处**：[生命周期里程碑 · 土星回归 ~29.5]。

## W06 · 天王星对冲（Uranus Opposition）~42 岁 · 中年环顾

- **配置**：行运 Uranus 与本命 Uranus 成 180° 对冲，约 41–43 岁发生。
- **解读要点**：象征"人生中的重要转折"，带来"要追赶忘了做的事"的紧迫感，关系 / 职业可能快速变化。**缓冲语同步**：若对自己充实地活过感到满意，尝试过不同的事，意外变化和不安会少很多。
- **心理画像**：中场环顾——"这是我想要的人生吗？"镜子不预言你会离婚或买跑车，只说现在是中场时间。
- **出处**：[生命周期里程碑 · 天王星对冲 ~42]。

## W07 · 水星行运刑太阳（Mercury square Sun）· 短期沟通摩擦

- **配置**：行运 Mercury square 本命 Sun，持续数日。
- **解读要点**：刑相=张力与摩擦。水星（沟通 / 思维）刑太阳（自我），象征这几天思维与自我主张之间有摩擦，说话容易带刺或急着辩白。
- **心理画像**：这几天"有纹理的玻璃"——沟通领域有摩擦色调。但纹理不是命运，不需要把摩擦当"必须辩赢"的许可证；它会过去（水星走得快）。
- **出处**：[相位象征光谱 · 刑相]；[内行星行运 · 短期主题]。

## W08 · 外行星星群同座（Capricorn Stellium H9）· 世代 + 个人

- **配置**：Saturn、Uranus、Neptune 同在 Capricorn H9（同一代人共享摩羯座）。
- **解读要点**：三颗外行星同座是**世代效应**（一代人共享的社会 / 信念氛围），不能直接当个人性格标签。个体解读落在它们共同所落的 H9（信念 / 高等心智 / 远行）以及与个人行星（日 / 月 / 水 / 金 / 火）的相位上。
- **心理画像**：这一代人集体在"信念 / 结构 / 权威"（9 宫摩羯）上经历压缩与重塑；个人则看这三颗如何触发自己的太阳 / 月亮。
- **出处**：[外行星生命周期 · 世代效应]；[宫位心理学 · 9宫]。

## W09 · 冥王星行运合上升（Pluto conjunct Ascendant）· 深层重塑

- **配置**：行运 Pluto 合本命 Ascendant，持续约 1–2 年（冥王走得极慢）。
- **解读要点**：冥王星象征深层转化 / 剥离 / 重生。合上升时，"你呈现给世界的那个面具 / 身份"被深层重塑——旧的自我形象瓦解，新的诞生。**不渲染为恐怖**。
- **心理画像**：像蛇蜕皮——不是毁灭，是身份的深层更新。这个季节长（数年），走完你会像换了一个人。季节会换。
- **出处**：[外行星生命周期 · 冥王转化]。

## W10 · 组合盘太阳摩羯 + 月亮巨蟹（Composite Sun Cap / Moon Can）

- **配置**：两人组合盘（中点法）太阳 Capricorn，月亮 Cancer。
- **解读要点**：组合盘属于"关系本身"这个第三实体，不属任何一方。组合太阳摩羯=关系核心目的以结构 / 责任 / 长远为底色；组合月亮巨蟹=关系情感基调以滋养 / 家 / 安全为底色。太阳拱或六合月亮是好标记（舒适与温情）。
- **心理画像**：这关系像"共同经营一个长远的家"——以责任为骨架，以滋养为情感。镜子照的是关系场的色调，不是"一定会幸福"的判决。
- **出处**：[组合盘第三实体]；[组合盘日月 · 关系双核]。

## W11 · 比较盘：A 金星刑 B 火星（Synastry Venus square Mars）

- **配置**：A 的 Venus 与 B 的 Mars 成 90° 刑相。
- **解读要点**：比较盘像"两个乐手的化学反应"。A 的价值 / 爱（金）与 B 的行动 / 欲望（火）相刑，象征关系中"被吸引又被摩擦"的经典张力——欲望与价值观持续对拉。
- **心理画像**：强烈的吸引伴随持续的摩擦，是"化学反应强但需要磨合"的镜像。不预测关系成败——镜子照出这对乐手之间的火花，能不能合奏好取决于双方。
- **出处**：[比较盘 Synastry · 化学反应]；[相位象征光谱 · 刑相]。

## W12 · 次限月亮进入天蝎座（Progressed Moon into Scorpio）· 情感周期切换

- **配置**：次限推进（出生 1 天 = 1 年）中，推进月亮进入天蝎座，持续约 2.5 年。
- **解读要点**：次限月亮约 27.5 年走完一圈，象征内在情感需求的人生季节。进入天蝎=这两年半情感需求转向深度、直面、转化，表面的寒暄不再满足。
- **心理画像**：内在情感季节从"轻"转"深"——这两年更想触碰关系与自我的深层，而非浮于表面。季节会换，不必把这段深度当成永恒身份。
- **出处**：[次限推进 Secondary Progressions · 次限月亮周期]。
