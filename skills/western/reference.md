## 表四 · 相位表（Aspects）

| 角度 | 名称 | 性质 | 色彩 | 建议容许度 |
|---|---|---|---|---|
| 0° | 合相 Conjunct | 融合 / 强化 | 两星能量合一 | 内行星 ~8°，外行星 ~6° |
| 60° | 六合 Sextile | 机会 / 友善 | 轻松的潜力通道 | ~4° |
| 90° | 刑相 Square | 张力 / 摩擦 | 需主动协调的拉力 | 内行星 ~8°，外 ~5° |
| 120° | 三合 Trine | 流动 / 和谐 | 顺畅的天赋通道 | ~8° |
| 180° | 对冲 Opposition | 极化 / 对立 | 两端拉扯需整合 | ~8° |
| （次相）150° | 梅花相 Quincunx | 调整 / 不适配 | 需调适的不协调 | ~3° |
| （次相）45°/135° | 半刑/八分相 | 细微张力 | 次级摩擦 | ~2° |

> 相位是"镜子的滤镜"，**不是行为许可证**：刑相≠可发脾气，冲相≠必须分手。相位越紧密影响越集中。

## 表五 · 行运与次限推进要点

### 行运 Transit（当下天空 ↔ 本命盘）

| 类别 | 行星 | 时间尺度 | 季节主题 |
|---|---|---|---|
| 内行星 | 月 / 水 / 金 / 火 | 数日–数周 | 短期情绪气候（月~2天，日~1年回归） |
| 外行星 | 木星 | ~12 年一周 | **扩张春**：乐观、信念、机会（警惕坐享好运） |
| 外行星 | 土星 | ~29.5 年一周 | **收敛冬**：结构、责任、盘点 |
| 外行星 | 天王星 | ~84 年一周 | **突破雷暴**：自由、突变、觉醒 |
| 外行星 | 海王星 | ~165 年一周 | **溶解雾季**：理想、幻象、消融 |
| 外行星 | 冥王星 | ~248 年一周 | **深层重塑**：剥离、转化、重生 |

### 生命周期里程碑行运

| 里程碑 | 约年龄 | 象征 |
|---|---|---|
| 土星对冲 Saturn Opposition | ~15 / 44 / 74 岁 | 重评与结构调整 |
| 土星回归 Saturn Return | ~29.5 岁 | 成年期结构确立 |
| 天王星对冲 Uranus Opposition | ~41–43 岁 | 中年环顾（缓冲：若已充实活过，变化较缓） |

### 次限推进 Secondary Progressions（出生 1 天 = 1 年）

- **次限月亮**：约 27.5 年走完一圈本命盘，象征情感需求的人生季节（约每宫 2.5 年）。
- **次限太阳 / 水星 / 金星 / 火星**：每年推进约 1°，象征内在成熟度的缓慢演化。
- 行运=当下气候；次限=内在成熟时钟；两者对照读"现在外在季节 vs 内在季节"。

## 表六 · 四元素心理学速查

| 元素 | 星座 | 心理基调 | 过盛表现 | 缺失表现 |
|---|---|---|---|---|
| 火 Fire | 白羊 / 狮子 / 射手 | 热情、直觉、行动、自我表达 | 急躁、自我中心、燃烧过快 | 犹豫、缺动力、难启动 |
| 土 Earth | 金牛 / 处女 / 摩羯 | 务实、物质、结构、耐心 | 僵化、固执、过度现实 | 漂浮、不落地、缺结构 |
| 风 Air | 双子 / 天秤 / 水瓶 | 思维、社交、理念、客观 | 思虑过度、疏离、空谈 | 情绪化、缺抽离、难客观 |
| 水 Water | 巨蟹 / 天蝎 / 双鱼 | 情感、直觉、共鸣、滋养 | 泛滥、黏着、边界模糊 | 抽离、难触碰情绪、麻木 |

| 模态 | 星座 | 心理基调 |
|---|---|---|
| 基本 Cardinal | 白羊 / 巨蟹 / 天秤 / 摩羯 | 开创、启动、推动、主导 |
| 固定 Fixed | 金牛 / 狮子 / 天蝎 / 水瓶 | 稳定、坚持、固化、深耕 |
| 变动 Mutable | 双子 / 处女 / 射手 / 双鱼 | 适应、灵活、分散、过渡 |

> 数本命盘各元素 / 模态星群分布：缺某元素=需刻意发展；某元素过盛=需平衡。元素是"心理能量基调"，非性格判决。
