子平真诠核心格局宪章 (Ziping Core)
基于清代沈孝瞻《子平真诠》原著正统立法宪章，建立确定性格局与相神成败推演体系。
核心公理与能力体系
月令立格与纯杂律 (cap-zpzq-01)：
八字用神专求月令，以日为主，以月令提纲司令定格。
纯者贵（各司其职互不相碍，信噪比高），杂者贱（官杀混杂、伤官见官互不相谋）。
相神宪章与成败救应 (cap-zpzq-02)：
“伤用神甚于伤身，伤相神甚于伤用”。相神是用神运转的核心中枢。
Grade A：相神天透地藏完好无伤。
Grade B：相神受克但局中有解药救应（如官逢伤而印护，财逢劫而食化）。
Grade C：破相倒戈，局无解救，格局破败。
用神动态变化 (cap-zpzq-03)：
地支三合三会重构月令五行，监控化格善恶。
吉凶顺逆两治模型 (cap-zpzq-04)：
四吉神（财官印食）顺用生护之；四凶神（杀伤枭刃）逆用约束制化之。凶神制化得宜，威权大贵。
行运成变格 (cap-zpzq-05)：
原局缺运能成之，原局成运能破之。干主五年虚名，支主五年实权基业。
墓库先后律 (cap-zpzq-06)：
辰戌丑未为归宿真根，严禁妄冲拔根。年月为先，日时为后。
