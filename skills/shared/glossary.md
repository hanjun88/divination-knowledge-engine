## 二、六爻专属术语

| 术语 | 定义 | 互参 |
|---|---|---|
| 用神 | 所占事类对应的六亲爻 | 八字"用神"概念不同——六爻为所占事类之爻，八字为扶抑日主之神 |
| 原神 | 生用神之爻 | 八字"喜神/印比"概念 |
| 忌神 | 克用神之爻 | 八字"忌神"概念一致 |
| 仇神 | 克原神生忌神之爻 | 八字"仇神"概念 |
| 世爻 | 卦中代表求测人/我方之爻 | 八字"日主/我"概念 |
| 应爻 | 卦中代表对方/事类之爻 | 八字"月令/提纲"概念 |
| 月建 | 占时月支，掌一月之权 | 八字"月令"概念一致——均为提纲 |
| 日辰 | 占时日支，为六爻之主宰 | 八字"日支"概念不同——六爻日辰权重极高 |
| 动爻 | 老阳○/老阴×发动之爻 | 八字"透干"概念——动则有变 |
| 变爻 | 动爻所化之爻 | 八字"大运"概念——为后来之变 |
| 回头生/克 | 变爻生/克本位动爻 | 八字"大运扶/克日主"概念 |
| 月破 | 月建冲爻 | 八字"月令冲克" |
| 旬空 | 爻值旬空 | 八字"空亡" |
| 暗动 | 静爻旺相被日辰冲 | 八字"暗冲"概念 |
| 六冲/六合 | 卦爻相冲/相合 | 八字"冲合" |
| 三合局 | 申子辰水局等三支合 | 八字"三合局"概念一致 |
| 六神 | 青龙朱雀勾陈螣蛇白虎玄武 | 紫微"煞曜"概念——均为附托之神，权重轻 |

| 飞神 | 压伏神之爻 | 八字"透出"概念——飞神空破伏神易出 |

| 伏吟 | 卦变伏吟（如乾变乾） | 八字"伏吟"概念——事重难进 |
| 化进/退神 | 动爻化同气前/后退 | 八字"进运/退运" |

## 六、三体系断法总则对比

| 维度 | 六爻 | 紫微 | 八字 |
|---|---|---|---|
| **断事性质** | 具体一事一时（当下占） | 一生命局（先天定数） | 一生命局（先天定数） |
| **时间粒度** | 应日时月 | 大限十年/小限一年 | 大运十年/流年一年 |
